Audiotext можна використовувати й із командного рядка, наприклад щоб транскрибувати зі скриптів. Є три команди:

- `transcribe`: транскрибує файл, файли папки або відео з YouTube.
- `watch`: транскрибує файли, що додаються до папки, доки її не зупинять через `Ctrl+C`.
- `check-update`: перевіряє, чи доступна нова версія, і виводить посилання для її завантаження.

Невказані параметри беруть значення з налаштувань застосунку. Транскрипції завжди зберігаються поруч із кожним транскрибованим файлом або в папці, вказаній через `--output-dir` (у ній відтворюються підпапки транскрибованої папки).

## Запуск

Встановлений застосунок запускає командний рядок, коли отримує одну з його команд:

| Система | Команда |
| --- | --- |
| Linux | `audiotext` (встановлюється в `~/.local/bin` скриптом `install.sh`) |
| macOS | `/Applications/Audiotext.app/Contents/MacOS/Audiotext` |
| Windows | `audiotext-cli.exe` у папці, куди встановлено Audiotext (типово `%LOCALAPPDATA%\Programs\Audiotext`) |

Якщо ви [запускаєте його з вихідного коду](/uk/help/contributing/#підготовка-проєкту), використовуйте натомість `uv run src/cli.py`.

## Приклади

```bash
# Транскрибувати файл. Текст також виводиться, тож його можна перенаправити
audiotext transcribe interview.mp3 --language es --output-types txt,srt

# Транскрибувати файли папки з визначенням мовців
audiotext transcribe recordings/ --diarize --speakers 2 --output-dir transcriptions/

# Транскрибувати відео з YouTube за допомогою Whisper API
audiotext transcribe "https://www.youtube.com/watch?v=…" --method whisper-api

# Транскрибувати зустріч за допомогою Whisper API з ключовими словами й контекстом
audiotext transcribe meeting.m4a --method whisper-api \
    --openai-model gpt-transcribe --keywords "Audiotext, WhisperX" \
    --prompt "Зустріч про наступну версію"

# Зберегти субтитри й документ Word, створити підсумок і перекласти іспанською
audiotext transcribe talk.mp4 --output-types srt,docx --summarize --translate-to es

# Транскрибувати файли, що додаються до папки, до зупинки через Ctrl+C
audiotext watch inbox/ --output-types srt

# Те саме, але спершу транскрибуються файли, які вже є в папці
audiotext watch inbox/ --existing
```

## Параметри

| Параметр | Опис |
| --- | --- |
| `-m`, `--method` | Метод транскрипції: `whisperx`, `whisper-api` або `google` |
| `-l`, `--language` | Мова аудіо у вигляді коду ISO 639-1 (наприклад, `uk`) або `auto` для визначення (не підтримується Google) |
| `-t`, `--output-types` | Типи вихідних файлів через кому з `aud`, `json`, `srt`, `txt`, `tsv`, `vtt`, `md`, `docx` і `ass` (наприклад, `txt,srt,md`) |
| `-o`, `--output-dir` | Папка для збереження транскрипцій (типово — поруч із кожним транскрибованим файлом) |
| `--overwrite` | Знову транскрибувати файли, які вже мають транскрипцію, замінюючи її |
| `--existing` | (лише `watch`) Спершу транскрибувати файли, які вже є в папці й ще не мають транскрипції |
| `-p`, `--prompt` | Про що запис, наприклад тема чи обставини (не підтримується Google) |
| `-k`, `--keywords` | Імена, терміни або абревіатури із запису через кому, щоб вони писалися правильно (не підтримується Google) |
| `--translate` | Перекладати аудіо англійською під час транскрипції (не підтримується Google). Для інших мов див. `--translate-to` |
| `-q`, `--quiet` | Виводити лише помилки |
| `-v`, `--verbose` | Виводити журнали для налагодження помилок |
| `--version` | Вивести версію Audiotext |

Типи виводу, які метод транскрипції не зберігає сам (наприклад, `md` або `docx`), експортуються з його результату, як у застосунку. `aud` зберігає лише WhisperX.

**Параметри підсумку й перекладу**

| Параметр | Опис |
| --- | --- |
| `--summarize` | Створити підсумок кожної транскрипції з ключовими моментами й розділами у файлі `.summary.md` |
| `--summary-provider` | Постачальник мовної моделі, що створює підсумок: `openai`, `anthropic`, `deepseek`, `gemini`, `mistral`, `grok` або `ollama` |
| `--summary-model` | Мовна модель, що створює підсумок |
| `--translate-to` | Перекласти кожну транскрипцію мовою (код ISO 639-1); переклад зберігається в її типах вихідних файлів (наприклад, `talk.es.srt`) |
| `--translation-provider` | Постачальник перекладів: ті самі, що для `--summary-provider`, а також `deepl` або `google` |
| `--translation-model` | Мовна модель для перекладу, для постачальників мовних моделей |

Якщо їх не вказано, використовуються постачальники й моделі з налаштувань застосунку. Див. [Постачальники](/uk/guides/summary-and-translation/#постачальники).

**Параметри WhisperX**

| Параметр | Опис |
| --- | --- |
| `--diarize` | Визначати мовців |
| `--speakers` | Кількість мовців під час визначення (`0` — визначити автоматично) |
| `--model-size` | Модель, наприклад `small` або `large-v2` (див. [Рушії](/uk/reference/engines/#модель)) |
| `--compute-type` | `int8`, `float16` або `float32` |
| `--batch-size` | Розмір пакета |
| `--cpu` | Запускати на процесорі, а не на відеокарті NVIDIA чи графічному процесорі Mac |

**Параметри Whisper API**

| Параметр | Опис |
| --- | --- |
| `--openai-model` | Модель транскрипції: `whisper-1`, `gpt-transcribe` або `gpt-4o-transcribe-diarize` |

Виконайте `audiotext transcribe --help`, щоб побачити всі параметри та їхні значення.

## Вивід і код завершення

Перебіг виконання виводиться в стандартний потік помилок (сховайте його за допомогою `--quiet`), а текст транскрипції одного файлу — у стандартний вивід. Команда завершується з кодом `1`, якщо не вдалася транскрипція, підсумок або переклад, і з кодом `130`, якщо її зупинено через `Ctrl+C`.

Якщо ключ API постачальника для `--summarize` або `--translate-to` не задано, команда зупиняється до транскрипції. Про невдалий підсумок або переклад повідомляється без втрати транскрипції, яку однаково збережено.

Ключі API беруться із застосунку або з їхніх [змінних середовища](/uk/reference/files-and-data/#змінні-середовища), наприклад `OPENAI_API_KEY`, `GOOGLE_API_KEY` і `HF_TOKEN` (для визначення мовців).
