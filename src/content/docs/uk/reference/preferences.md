**Уподобання** містять налаштування, які не змінюються з кожною транскрипцією. Відкрийте їх шестірнею у правому верхньому куті вікна. Зміни зберігаються автоматично.

## Загальні

- **Оформлення**: **Системна** (як у системі), **Світла** або **Темна**.
- **Мова інтерфейсу**: мова Audiotext або **Мова системи**. Її можна змінити, коли не виконується жодна транскрипція. Див. [доступні мови](/uk/reference/formats-and-languages/#мови-інтерфейсу).
- **Сповіщення**: показує системне сповіщення, коли транскрипція готова (для папки — коли готові всі її файли, а для папки під стеженням — щоразу, коли готовий новий файл). Увімкнено за замовчуванням. У macOS вони надходять від **Редактора скриптів**, а у Windows — від **Windows PowerShell**, тож їх дозволяють або вимикають для цих програм у налаштуваннях системи. У Linux для них потрібен `notify-send` (пакет `libnotify-bin` або `libnotify`).

## ШІ

Постачальники [підсумків і перекладів](/uk/guides/summary-and-translation/):

- **Підсумок** → **Постачальник** і **Модель**.
- **Переклад** → **Постачальник** і **Модель**. DeepL і Google Translate не мають моделей на вибір.
- **Ollama** → **URL сервера**: адреса Ollama, типово `http://localhost:11434`.

Залиште поле **Модель** порожнім, щоб використовувати типову модель постачальника. Кнопка поруч із постачальником задає його ключ API.

## Ключі API

Ключі кожної служби. Натисніть **Задати…**, щоб ввести ключ, або **Змінити…**, щоб замінити його (залиште поле порожнім, щоб видалити ключ). Вони зберігаються у сховищі облікових даних системи.

| Ключ | Для чого потрібен |
| --- | --- |
| Ключ API OpenAI | Whisper API, а також підсумки й переклади з OpenAI |
| Ключ API Anthropic | Підсумки й переклади з Claude |
| Ключ API DeepSeek | Підсумки й переклади з DeepSeek |
| Ключ API Gemini | Підсумки й переклади з Gemini (з Google AI Studio) |
| Ключ API Mistral | Підсумки й переклади з Mistral |
| Ключ API xAI | Підсумки й переклади з Grok |
| Ключ API DeepL | Переклади з DeepL (ключі безкоштовного тарифу теж підходять) |
| Ключ Google API | Google Speech-to-Text понад безкоштовний ліміт і Google Translate (Cloud Translation API) |
| Токен Hugging Face | Визначення мовців у WhisperX |

:::caution
Кожен постачальник бере плату за використання свого API, за що Audiotext не відповідає. Якщо OpenAI повертає помилку `429` з новим ключем, див. [Усунення несправностей](/uk/help/troubleshooting/#whisper-api-повертає-помилку-429).
:::

## WhisperX

**Тип обчислень**, **Розмір пакета** й **Використовувати CPU**. Див. [розширені параметри WhisperX](/uk/reference/engines/#розширені-параметри).

## Субтитри

Параметри файлів `.srt` і `.vtt`, які зберігаються під час транскрипції папки за допомогою WhisperX:

- **Виділяти слова**: підкреслює кожне слово в момент його вимови. Типово вимкнено.
- **Макс. кількість рядків**: максимальна кількість рядків у кожному субтитрі. Типово `2`.
- **Макс. ширина рядка**: максимальна кількість символів у рядку до перенесення. Типово `42`.
