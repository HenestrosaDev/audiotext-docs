**Уподобання** містять налаштування, які не змінюються з кожною транскрипцією. Відкрийте їх шестірнею у правому верхньому куті вікна. Зміни зберігаються автоматично.

## Загальні

- **Оформлення**: **Системна** (як у системі), **Світла** або **Темна**.
- **Розмір інтерфейсу**: розмір тексту й елементів керування, від 80 % до 200 %. За замовчуванням `100%`. Зміна застосовується одразу.
- **Мова інтерфейсу**: мова Audiotext або **Мова системи**. Див. [доступні мови](/uk/reference/formats-and-languages/#мови-інтерфейсу).
- **Формат дати**: як показуються дати транскрипцій мовою інтерфейсу: короткий (`04.10.26`), середній (`4 жовт. 2026 р.`, типовий), довгий (`4 жовтня 2026 р.`) або ISO (`2026-10-04`). Меню показує кожен формат на прикладі.
- **Формат часу**: **Автоматично** (годинник мови інтерфейсу), 12-годинний (`1:30 PM`) або 24-годинний (`13:30`).
- **Сповіщення**: показує системне сповіщення, коли транскрипція готова (для папки — коли готові всі її файли, а для папки під стеженням — щоразу, коли готові нові файли, одним сповіщенням). Увімкнено за замовчуванням. У macOS вони надходять від **Редактора скриптів**, а у Windows — від **Windows PowerShell**, тож їх дозволяють або вимикають для цих програм у налаштуваннях системи. У Linux для них потрібен `notify-send` (пакет `libnotify-bin` або `libnotify`).
- **Перевіряти оновлення автоматично**: під час запуску застосунку перевіряє наявність нової версії і, якщо вона є, показує на верхній панелі кнопку **Доступна версія …**, яка відкриває сторінку завантаження. Попередні версії не пропонуються. Увімкнено за замовчуванням.

## Постачальники

Постачальники [підсумків, запитань і перекладів](/uk/guides/summary-and-translation/):

- **Підсумок** → **Постачальник** і **Модель**.
- **Запитати** → **Постачальник** і **Модель**: ті, що відповідають на запитання про транскрипції. Поки ви їх не зміните, це постачальник і модель підсумків.
- **Переклад** → **Постачальник** і **Модель**. DeepL і Google Translate не мають моделей на вибір.
- **Ollama** → **URL сервера**: адреса Ollama, типово `http://localhost:11434`.

Залиште поле **Модель** порожнім, щоб використовувати типову модель постачальника. Кнопка поруч із постачальником задає його ключ API.

## Ключі API

Ключі кожної служби. Натисніть **Задати ключ API…**, щоб ввести ключ, або **Змінити ключ API…**, щоб замінити його (залиште поле порожнім, щоб видалити ключ). Вони зберігаються у сховищі облікових даних системи. Їх згруповано за призначенням, а задані ключі позначено галочкою.

| Група | Ключ | Для чого потрібен |
| --- | --- | --- |
| **Постачальники LLM** | Ключ API OpenAI | Whisper API, а також підсумки, запитання й переклади з OpenAI |
| | Ключ API Anthropic | Підсумки, запитання й переклади з Claude |
| | Ключ API DeepSeek | Підсумки, запитання й переклади з DeepSeek |
| | Ключ API Gemini | Підсумки, запитання й переклади з Gemini (з Google AI Studio) |
| | Ключ API Mistral | Підсумки, запитання й переклади з Mistral |
| | Ключ API xAI | Підсумки, запитання й переклади з Grok |
| **Переклад** | Ключ API DeepL | Переклади з DeepL (ключі безкоштовного тарифу теж підходять) |
| | Ключ Google API | Google Speech-to-Text понад безкоштовний ліміт і Google Translate (Cloud Translation API) |
| **Транскрипція** | Токен Hugging Face | Визначення мовців у WhisperX |

:::caution
Кожен постачальник бере плату за використання свого API, за що Audiotext не відповідає. Якщо OpenAI повертає помилку `429` з новим ключем, див. [Усунення несправностей](/uk/help/troubleshooting/#whisper-api-повертає-помилку-429).
:::

## Транскрипція

Параметри рушіїв, кожен у своєму розділі.

### WhisperX

**Тип обчислень**, **Розмір пакета** й **Використовувати CPU**. Див. [розширені параметри WhisperX](/uk/reference/engines/#розширені-параметри). На Mac з Apple Silicon WhisperX транскрибує на його графічному процесорі, якщо не ввімкнено **Використовувати CPU**. Див. [На Mac](/uk/reference/engines/#на-mac). На графічному процесорі Mac підказки **Тип обчислень** і **Розмір пакета** повідомляють, що вони не застосовуються, а **Використовувати CPU** має посилання на **Підтримувані моделі**.

### Whisper API

**Температура** й **Часові мітки слів**. Див. [параметри Whisper API](/uk/reference/engines/#параметри).

## Субтитри

Як діляться субтитри: показані на відео й у режимі **Субтитри**, експортовані файли субтитрів і [відео із субтитрами](/uk/guides/transcript/#експорт-відео-із-субтитрами). Кожен параметр має значення для горизонтальних відео й для вертикальних (вищих, ніж ширших, наприклад для телефонів), які вужчі:

| Параметр | Горизонтальні | Вертикальні |
| --- | :---: | :---: |
| **Макс. рядків у субтитрі** | `2` | `2` |
| **Макс. символів у рядку** | `42` | `24` |
| **Китайська, японська та корейська**: символів у рядку цими мовами, символи яких приблизно вдвічі ширші за латинські | `16` | `10` |

Рядки субтитру вирівнюються за довжиною, а мови без пробілів переносяться між символами.

**Виділяти слова** підкреслює у файлах `.srt` і `.vtt` кожне слово в момент його вимови. Типово вимкнено.

## Про програму

Версія Audiotext і посилання на цю документацію, вихідний код на GitHub і сторінку підтримки. **Перевірити оновлення** одразу перевіряє наявність нової версії: якщо вона є, кнопка змінюється на **Завантажити** й відкриває її сторінку.
