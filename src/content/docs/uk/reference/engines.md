Audiotext транскрибує за допомогою одного з трьох рушіїв, який вибирається на картці **Рушій** у [налаштуваннях транскрипції](/uk/guides/transcription-settings/#рушій).

| | WhisperX | Whisper API | Google API |
| --- | --- | --- | --- |
| Працює на | Вашому комп'ютері | Серверах OpenAI | Серверах Google |
| Інтернет | Лише для завантаження моделей | Потрібен | Потрібен |
| Вартість | Безкоштовно, без обмежень | Платно | Безкоштовний ліміт (60 хв/міс) або платно з ключем API |
| Визначає мову | ✓ | ✓ | ✗ |
| Перекладає | ✓ | ✓ | ✗ |
| Часові мітки | ✓ | Залежно від моделі | ✗ |
| Визначає мовців | ✓ (токен Hugging Face) | `gpt-4o-transcribe-diarize` | ✗ |
| Таймінг слів | ✓ | `whisper-1` | ✗ |
| Живий текст | ✓ | ✗ | ✗ |

## WhisperX

[WhisperX](https://github.com/m-bain/whisperX) — швидка реалізація Whisper від OpenAI, що працює на вашому комп'ютері, тож аудіо ніколи його не залишає. Працює на процесорі або, значно швидше, на відеокарті NVIDIA з CUDA.

### Модель

Більші моделі точніші, але повільніші й потребують більше пам'яті. Модель завантажується під час першого використання.

| Модель | Параметри | Потрібна VRAM |
| :---: | :---: | :---: |
| `tiny`, `tiny.en` | 39 M | ~1 ГБ |
| `base`, `base.en` | 74 M | ~1 ГБ |
| `small`, `small.en` | 244 M | ~2 ГБ |
| `distil-small.en` | 166 M | ~2 ГБ |
| `medium`, `medium.en` | 769 M | ~5 ГБ |
| `distil-medium.en` | 394 M | ~3 ГБ |
| `large-v1`, `large-v2`, `large-v3` | 1550 M | <8 ГБ |
| `large-v3-turbo` | 809 M | ~6 ГБ |
| `distil-large-v2`, `distil-large-v3`, `distil-large-v3.5` | 756 M | ~5 ГБ |

- **`large-v2`** використовується типово, бо `large-v3` частіше галюцинує й повторює текст, особливо деякими мовами, як-от японською, і пропускає більше розділових знаків.
- **`large-v3-turbo`** — полегшена версія `large-v3`, значно швидша й майже така сама точна.
- Моделі із закінченням **`.en`** (`tiny.en`, `base.en`, `small.en`, `medium.en`) і **дистильовані** моделі (`distil-small.en`, `distil-medium.en`, `distil-large-v2`, `distil-large-v3`, `distil-large-v3.5`) транскрибують лише англійську. Вони швидші за багатомовні моделі того самого розміру.

:::tip
Щоб швидко спробувати Audiotext, виберіть `tiny` або `small`. Для найкращої якості використовуйте `large-v2` або `large-v3-turbo` на відеокарті.
:::

### Розширені параметри

Розташовані в **Уподобання** → **WhisperX**. Змінюйте їх, лише якщо є проблеми або ви знаєте, що робите: відеокарта, якій забракло пам'яті, може завісити систему.

- **Тип обчислень**: точність чисел моделі. `float16` швидший на відеокартах (типовий із CUDA). `int8` потребує менше пам'яті й використовується типово на процесорі, бо багато процесорів неефективно працюють із `float16`. `float32` найточніший, для відеокарт із понад 8 ГБ VRAM.
- **Розмір пакета**: скільки частин аудіо обробляється одночасно (типово `8`). Впливає не на якість, а лише на швидкість. Зменште, якщо бракує пам'яті; рекомендовано не більше `16`.
- **Використовувати CPU**: запускає WhisperX на процесорі. Завжди ввімкнено, якщо відеокарту з CUDA не знайдено.

## Whisper API

Використовує [API OpenAI для перетворення мовлення на текст](https://platform.openai.com/docs/guides/speech-to-text). Призначений для комп'ютерів, на яких WhisperX працює повільно, і потребує ключа API OpenAI (див. [Ключі API](/uk/reference/preferences/#ключі-api)).

| Модель | Часові мітки | Мовці | Примітки |
| --- | :---: | :---: | --- |
| `whisper-1` (типова) | ✓ | ✗ | Можна відтворювати по сегментах і створювати субтитри. Перекладає англійською. |
| `gpt-transcribe` | ✗ | ✗ | Точніша, але без часових міток. |
| `gpt-4o-transcribe-diarize` | ✓ | ✓ | Визначає мовців. Не використовує ключові слова й опис. |

Переклади англійською завжди виконує `whisper-1`, бо це єдина модель, що перекладає.

Довгі записи діляться на фрагменти до 10 хвилин, розрізані на паузі, щоб не розривати слова, оскільки API відхиляє файли понад 25 МБ. З `whisper-1` кінець кожного фрагмента передається наступному як контекст; з `gpt-4o-transcribe-diarize` разом із наступними фрагментами надсилається зразок голосу кожного мовця, щоб зберегти їхні мітки.

### Параметри

- **Формат відповіді** (картка «Вивід», для папок): `text` (типово), `json`, `verbose_json`, `srt` або `vtt`. Для субтитрів і `verbose_json` потрібна модель із часовими мітками.
- **Температура** (Уподобання → Whisper API): від 0 до 1. Високі значення, як-от 0,8, роблять результат випадковішим, низькі, як-от 0,2, — зосередженішим. При 0 (типово) модель сама підвищує її за потреби.
- **Часові мітки слів** (Уподобання → Whisper API): чи повертає `whisper-1` мітки кожного слова, щоб підсвічувати його під час відтворення. Триває довше. Типово ввімкнено.

## Google API

Використовує [Google Speech-to-Text API](https://cloud.google.com/speech-to-text). Він не розставляє розділові знаки (їх додає Audiotext), а його якість нижча, ніж у Whisper, тож транскрипції часто потребують виправлень. Він не визначає мову, не перекладає й повертає звичайний текст без часових міток.

Без ключа API використовується безкоштовний ліміт — 60 хвилин на місяць. Щоб розширити його, задайте ключ Google API. Google бере плату за використання, за що Audiotext не відповідає.
