Audiotext зберігає ваші дані на вашому комп'ютері. Нічого нікуди не надсилається, якщо ви не використовуєте віддалений рушій (Whisper API або Google API) чи постачальника ШІ, відмінного від Ollama.

## Папка користувацької конфігурації

Налаштування, історія й записи зберігаються в папці користувацької конфігурації, тож не зникають після оновлень:

| Система | Папка |
| --- | --- |
| Windows | `%APPDATA%\Audiotext` |
| macOS | `~/Library/Application Support/Audiotext` |
| Linux | `~/.config/audiotext` (або `$XDG_CONFIG_HOME/audiotext`) |

У ній містяться:

- `config.ini`: ваші налаштування. Видаліть його, щоб повернути типові значення.
- `history.json`: ваші транскрипції з підсумками, перекладами й виправленнями.
- `media/`: записи з мікрофона й аудіо, завантажене за URL, щоб їх можна було відтворити пізніше. Вони видаляються разом із відповідною транскрипцією з історії.

Щоб використовувати іншу папку, наприклад для портативного встановлення, задайте змінну середовища `AUDIOTEXT_CONFIG_DIR`.

:::note
Файл `config.ini` у папці застосунку містить типові налаштування й ніколи не змінюється.
:::

## Ключі API

Ключі API й токен Hugging Face зберігаються у сховищі облікових даних системи:

- **macOS**: Зв'язка ключів.
- **Windows**: Диспетчер облікових даних.
- **Linux**: Secret Service (наприклад, GNOME Keyring або KWallet).

Якщо в системі його немає (наприклад, на сервері без робочого столу), вони зберігаються у файлі `.env` у папці конфігурації, доступному для читання лише вашому користувачу. Ключі, які попередні версії зберігали в цьому файлі, переносяться до сховища облікових даних під час першого запуску застосунку.

Ключі використовуються **лише** для запитів до API відповідної служби.

## Змінні середовища

Змінні середовища з назвами ключів мають пріоритет над ключами, заданими в застосунку:

| Змінна | Служба |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI (Whisper API, підсумки, переклади) |
| `ANTHROPIC_API_KEY` | Claude |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `GEMINI_API_KEY` | Gemini |
| `MISTRAL_API_KEY` | Mistral |
| `XAI_API_KEY` | Grok (xAI) |
| `DEEPL_API_KEY` | DeepL |
| `GOOGLE_API_KEY` | Google Speech-to-Text і Google Translate |
| `HF_TOKEN` | Hugging Face (визначення мовців) |
| `AUDIOTEXT_CONFIG_DIR` | Папка налаштувань та історії |

## Моделі

Моделі WhisperX і визначення мовців завантажуються під час першого використання й кешуються Hugging Face у `~/.cache/huggingface` (або `%USERPROFILE%\.cache\huggingface` у Windows). Видаліть цю папку, щоб звільнити зайняте ними місце.
