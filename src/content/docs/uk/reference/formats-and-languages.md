## Аудіо- та відеоформати

Audiotext витягує звук із відеофайлів за допомогою FFmpeg, тож транскрибує і те, й інше.

**Аудіо**: `.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**Відео**: `.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## Вихідні формати

| Формат | Експорт | Папка (WhisperX) | Папка (Whisper API) |
| --- | :---: | :---: | :---: |
| Звичайний текст (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Документ Word (`.docx`) | ✓ | ✗ | ✗ |
| Субтитри (`.srt`) | ✓ | ✓ | `srt` |
| Вебсубтитри (`.vtt`) | ✓ | ✓ | `vtt` |
| Таблиця (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Мітки Audacity (`.aud`) | ✗ | ✓ | ✗ |

Див. [Експорт](/uk/guides/transcript/#копіювання-й-експорт) і [картку «Вивід»](/uk/guides/transcription-settings/#папка-й-вивід).
