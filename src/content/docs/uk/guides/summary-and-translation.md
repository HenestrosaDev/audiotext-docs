Коли транскрипція готова, Audiotext може створити її підсумок і перекласти її за допомогою мовної моделі або служби перекладу. Обидва зберігаються в історії, тож створюються лише один раз.

## Підсумок

Відкрийте режим **Підсумок** транскрипції й натисніть **Створити підсумок**. Мовна модель напише:

- **Підсумок** транскрипції.
- Її **ключові моменти**.
- Її **розділи**, якщо є часові мітки. Натисніть розділ, щоб відтворити аудіо з його початку.

**Створити знову** пише підсумок повторно (наприклад, після вибору іншої моделі). **Копіювати** копіює його, а [експорт](/uk/guides/transcript/#копіювання-й-експорт) у Markdown і Word його містить.

Якщо ключ API постачальника не задано, режим **Підсумок** запропонує його задати. Дуже довгі транскрипції (приблизно три години мовлення й більше) підсумовуються лише з початку.

## Переклад

Натисніть **Перекласти**, виберіть мову в полі **Перекласти** та **Постачальника**, потім підтвердьте. Переклад з'явиться на панелі праворуч від вихідного тексту.

- Якщо транскрипція має часові мітки, кожен сегмент перекладається окремо, тож переклад починається з тими самими часовими мітками: підсвічує сегмент, що відтворюється, а натискання сегмента відтворює його.
- Якщо ви редагували звичайний текст, перекладається відредагований текст, без часових міток.
- Перетягніть розділювач між текстами, щоб змінити їхній розмір, або двічі клацніть його, щоб повернути початкові розміри.
- Кнопка **Перекласти** також дає змогу **Сховати переклад**, **Перекласти іншою мовою…** або **Видалити переклад**.

### Виправлення й таймінг перекладу

Перекладу часто потрібен інший таймінг, ніж оригіналу, наприклад субтитри, які довше читати. Клацніть сегмент перекладу правою кнопкою, щоб:

- **Змінити текст…**: змінити його текст.
- **Змінити таймінг…**: змінити, коли він починається й закінчується, з точністю до мілісекунди. Вводьте час як `00:01:05,900`, `01:05,9` або `65.9`.
- **Додати сегмент після…**: додати сегмент, який типово заповнює проміжок до наступного.
- **Видалити сегмент**.

### Власний переклад

Щоб написати переклад самостійно, виберіть **Сам, з нуля** як **Постачальника**. Ключ API не потрібен. Переклад починається з часових міток транскрипції та порожніх сегментів, показаних як **Ще не перекладено**, а панель показує, скільки їх залишилося. Клацніть один із них правою кнопкою й виберіть **Перекласти текст…**: діалог показує вихідний текст, сказаний у цей час.

### Субтитри й експорт

- У транскрипціях відео увімкніть **Показувати як субтитри відео** в меню **Перекласти**, щоб показувати переклад як субтитри. Перемкнути їх можна й у меню відео. Див. [Відео із субтитрами](/uk/guides/transcript/#відео-із-субтитрами).
- Щоб зберегти переклад у файл, виберіть **Переклад** у меню **Експорт** або натисніть кнопку експорту перекладу. Він експортується в тих самих [форматах](/uk/guides/transcript/#копіювання-й-експорт), що й транскрипція, з мовою в назві файлу (наприклад, `video.es.srt`), тож відеоплеєри завантажують його разом із відео. Ще не перекладені сегменти до субтитрів не потрапляють.

:::tip
Щоб одразу отримати транскрипцію іншою мовою без постачальника, можна перекладати й під час транскрипції. Див. [Мова](/uk/guides/transcription-settings/#мова).
:::

## Постачальники

Постачальників вибирають в **Уподобання** → **ШІ**, окремо для підсумків і для перекладів.

| Постачальник | Типова модель | Ключ API |
| --- | --- | --- |
| OpenAI (типовий) | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude (Anthropic) | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini (Google) | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama (локально) | `llama3.2` | Не потрібен |

Залиште поле **Модель** порожнім, щоб використовувати типову модель постачальника, або введіть назву будь-якої іншої його моделі (наприклад, `claude-sonnet-5-5` або `deepseek-reasoner`).

Перекладати також можна за допомогою:

- **DeepL** — потрібен [ключ API DeepL](https://www.deepl.com/your-account/keys). Ключі безкоштовного тарифу теж підходять.
- **Google Translate** — використовується ключ Google API з увімкненим Cloud Translation API.

### Ollama

[Ollama](https://ollama.com) запускає моделі на вашому комп'ютері, без ключа API й без надсилання тексту будь-куди. Встановіть її, завантажте модель (наприклад, `ollama pull llama3.2`) і виберіть **Ollama** як постачальника. Якщо вона працює не за типовою адресою, змініть **URL сервера** в **Уподобання** → **ШІ** (типово `http://localhost:11434`).

:::note
Кожен постачальник бере плату за використання свого API, за що Audiotext не відповідає. Ключі API зберігаються у сховищі облікових даних системи. Див. [Файли й дані](/uk/reference/files-and-data/).
:::
