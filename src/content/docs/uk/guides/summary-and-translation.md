Коли транскрипція готова, Audiotext може створити її підсумок, відповісти на запитання про неї й перекласти її за допомогою мовної моделі або служби перекладу. Усе це зберігається в історії, тож створюється лише один раз.

## Підсумок

Відкрийте режим **Підсумок** транскрипції й натисніть **Створити підсумок**. Мовна модель напише:

- **Підсумок** транскрипції.
- Її **ключові моменти**.
- Її **розділи**, якщо є часові мітки. Натисніть розділ, щоб відтворити аудіо з його початку.

Під заголовком панель показує, яка модель створила підсумок і коли. Кнопки в її заголовку:

- **Знайти** (`Ctrl+F`, `⌘F` у macOS): шукає текст у підсумку.
- **Копіювати**: копіює його.
- **Експорт**: зберігає його окремо як звичайний текст, Markdown або документ Word з назвою на кшталт `video.summary.md`, щоб він не замінив транскрипцію. [Експорт](/uk/guides/transcript/#копіювання-й-експорт) транскрипції в Markdown і Word теж його містить.
- **Створити підсумок знову**: пише його повторно (наприклад, після вибору іншої моделі) після підтвердження, бо поточний буде замінено.

Якщо ключ API постачальника не задано, режим **Підсумок** запропонує його задати. Дуже довгі транскрипції (приблизно три години мовлення й більше) підсумовуються лише з початку.

## Запитання про транскрипцію

Відкрийте режим **Запитати**, введіть запитання в поле **Поставте запитання про транскрипцію…** (наприклад, що вирішили або хто щось сказав) і натисніть `Enter` або кнопку **Запитати**.

- Мовна модель відповідає на основі транскрипції та попередніх запитань і відповідей, тож запитання може на них посилатися (наприклад, «Чому?»).
- Якщо транскрипція має часові мітки, кожна відповідь посилається на частини транскрипції, де це сказано. Натисніть одну з них, щоб відтворити аудіо з цього місця.
- Запитання й відповіді зберігаються в історії разом із транскрипцією. Кошик у заголовку очищає розмову після підтвердження.

На запитання відповідає постачальник, вибраний для них в **Уподобання** → **ШІ** → **Запитати**; поки ви його не зміните, це постачальник підсумків. Як і для підсумків, із дуже довгих транскрипцій читається лише початок.

## Переклад

Натисніть **Перекласти**, виберіть мову в полі **Перекласти:** і постачальника в полі **Перекласти за допомогою:**, потім підтвердьте. Діалог пояснює, що робить вибраний постачальник, і пропонує задати його ключ API, якщо його бракує. Переклад з'явиться на панелі праворуч від вихідного тексту.

- Якщо транскрипція має часові мітки, вона перекладається за реченнями, з текстом до й після кожної частини як контекстом, тож переклад починається з часовими мітками кожного речення: підсвічує речення, що відтворюється, а натискання речення відтворює його.
- Якщо ви редагували звичайний текст, перекладається відредагований текст, без часових міток.
- Обидва тексти прокручуються разом і показують ту саму частину аудіо. Кругла кнопка на розділювачі між ними вмикає й вимикає це. Перетягніть розділювач, щоб змінити їхній розмір, або двічі клацніть його, щоб повернути початкові розміри.

Кнопки в заголовку перекладу дають змогу шукати й замінювати в ньому текст, копіювати його, експортувати, **Перекласти знову** (з тим самим постачальником і моделлю) і **Сховати переклад**. Кнопка **Перекласти** також дає змогу знову показати його, **Перекласти іншою мовою…** або **Видалити переклад**.

### Кілька мов

Транскрипцію можна перекласти кількома мовами, навіть одночасно, і кожен переклад зберігається. Заголовок панелі вибирає показаний переклад, показує, яку частину кожного перекладено, і закінчується пунктом перекладу іншою мовою. Переклад мовою, якою переклад уже є, замінює його після підтвердження, бо його виправлення буде втрачено.

### Виправлення й таймінг перекладу

Перекладу часто потрібен інший таймінг, ніж оригіналу, наприклад субтитри, які довше читати. Клацніть сегмент перекладу правою кнопкою, щоб:

- **Змінити текст…**: змінити його текст.
- **Змінити таймінг…**: змінити, коли він починається й закінчується, з точністю до мілісекунди. Вводьте час як `00:01:05,900`, `01:05,9` або `65.9`.
- **Додати сегмент після…**: додати сегмент, який типово заповнює проміжок до наступного.
- **Видалити сегмент**.

### Власний переклад

Щоб написати переклад самостійно, виберіть **Вручну** в полі **Перекласти за допомогою:**. Ключ API не потрібен. Переклад починається з порожнього сегмента для кожного субтитру транскрипції, показаного як **Ще не перекладено**, а панель показує, скільки їх залишилося. Клацніть один із них правою кнопкою й виберіть **Перекласти текст…**: діалог показує вихідний текст, сказаний у цей час.

### Субтитри й експорт

- У транскрипціях відео увімкніть **Показувати як субтитри відео** в меню **Перекласти**, щоб показувати переклад як субтитри. Перемкнути їх можна й у меню відео. Див. [Відео із субтитрами](/uk/guides/transcript/#відео-із-субтитрами).
- Щоб зберегти переклад у файл, натисніть кнопку експорту на його панелі. Він експортується в тих самих [форматах](/uk/guides/transcript/#копіювання-й-експорт), що й транскрипція, з мовою в назві файлу (наприклад, `video.es.srt`), тож відеоплеєри завантажують його разом із відео. Ще не перекладені сегменти до субтитрів не потрапляють. Те саме меню створює [копію відео із субтитрами](/uk/guides/transcript/#експорт-відео-із-субтитрами).

:::tip
Щоб одразу отримати транскрипцію іншою мовою без постачальника, можна перекладати й під час транскрипції. Див. [Мова](/uk/guides/transcription-settings/#мова).
:::

## Постачальники

Постачальників вибирають в **Уподобання** → **ШІ**, окремо для підсумків, запитань і перекладів.

| Постачальник | Типова модель | Ключ API |
| --- | --- | --- |
| OpenAI (типовий) | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude (Anthropic) | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini (Google) | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama (локально) | `llama3.2` | Не потрібен |

Залиште поле **Модель** порожнім, щоб використовувати типову модель постачальника, або введіть назву будь-якої іншої його моделі (наприклад, `claude-sonnet-5-5` або `deepseek-reasoner`).

Перекладати також можна за допомогою:

- **DeepL** — потрібен [ключ API DeepL](https://www.deepl.com/your-account/keys). Ключі безкоштовного тарифу теж підходять.
- **Google Translate** — використовується ключ Google API з увімкненим Cloud Translation API.

### Ollama

[Ollama](https://ollama.com) запускає моделі на вашому комп'ютері, без ключа API й без надсилання тексту будь-куди. Встановіть її, завантажте модель (наприклад, `ollama pull llama3.2`) і виберіть **Ollama** як постачальника. Якщо вона працює не за типовою адресою, змініть **URL сервера** в **Уподобання** → **ШІ** (типово `http://localhost:11434`).

:::note
Кожен постачальник бере плату за використання свого API, за що Audiotext не відповідає. Ключі API зберігаються у сховищі облікових даних системи. Див. [Файли й дані](/uk/reference/files-and-data/).
:::
