Перед транскрипцією Audiotext показує її налаштування, згруповані в картки. Вони запам'ятовуються на наступний раз, а кожна транскрипція зберігає налаштування, з якими її створено.

![Налаштування транскрипції файлу](/screenshots/transcription-settings.png)

## Рушій

**Метод транскрипції**:

| Рушій | Де працює | Вартість | Примітки |
| --- | --- | --- | --- |
| **WhisperX** (типовий) | Ваш комп'ютер | Безкоштовно й без обмежень | Приватно й офлайн. Більше можливостей: мовці, таймінг слів, живий текст. |
| **Whisper API** | Сервери OpenAI | Оплата за хвилину | Потрібен [ключ API OpenAI](/uk/reference/preferences/#ключі-api). Для комп'ютерів, на яких WhisperX працює повільно. |
| **Google API** | Сервери Google | Безкоштовний ліміт або платно | Нижча якість і немає часових міток. Ключ API необов'язковий. |

**Модель** залежить від рушія. У WhisperX більші моделі точніші, але повільніші. У Whisper API модель визначає, чи будуть у транскрипції часові мітки й мовці. Порівняння — у розділі [Рушії](/uk/reference/engines/).

## Мова

- **Мова аудіо**: типово **Автовизначення**. Якщо вибрати її вручну, можна уникнути помилок у коротких або змішаних записах. Google API не вміє визначати мову, тож для нього її треба вибрати.
- **Мова транскрипції**: типово **Як в аудіо**. Виберіть іншу мову, щоб перекласти аудіо під час транскрипції.

Якщо мови відрізняються, з'являються параметри розділу **Переклад**:

- **Перекладати за допомогою Whisper (рекомендовано)**: Whisper транскрибує й перекладає аудіо за один крок. Перекладає лише англійською.
- **Писати одразу потрібною мовою (_мова_, експериментально)**: Whisper просять одразу писати транскрипцію цією мовою. Для багатьох мов це працює добре, але перевіряйте результат.

Google API не вміє перекладати. Щоб пізніше перекласти транскрипцію будь-якою мовою за допомогою інших постачальників, використовуйте кнопку [Перекласти](/uk/guides/summary-and-translation/#переклад) у транскрипті.

## Контекст

Два необов'язкові поля, які допомагають моделі:

- **Ключові слова**: імена, терміни або абревіатури, що звучать у записі, через кому (наприклад, `Audiotext, WhisperX, Henestrosa`), щоб вони писалися правильно. Це лише підказки: ключове слово з'явиться, лише якщо воно звучить у записі.
- **Опис**: про що запис, наприклад його тема чи обставини (наприклад, `Інтерв'ю про розпізнавання мовлення`).

Їх використовують WhisperX і Whisper API, крім моделі `gpt-4o-transcribe-diarize`. Google API їх не використовує.

## Параметри

- **Таймінг слів** (WhisperX): вирівнює кожне слово за аудіо, щоб підсвічувати його під час відтворення. Триває трохи довше. Субтитри його вже використовують.
- **Виділяти мовлення**: перед транскрипцією приглушує музику й фоновий шум.
- **Визначати мовців** (WhisperX): позначає, хто говорить у кожній частині, наприклад `SPEAKER_00`. Якщо ви знаєте, скільки людей говорить, укажіть це в полі **Кількість мовців** (`0` — визначити автоматично). Потрібен безкоштовний токен Hugging Face; див. [Визначення мовців](#визначення-мовців). У Whisper API мовців визначає модель `gpt-4o-transcribe-diarize`.

### Визначення мовців

Модель, що визначає мовців, [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1), безкоштовна, але потребує токена Hugging Face:

1. Створіть обліковий запис на [Hugging Face](https://huggingface.co/join) і прийміть умови [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1).
2. Створіть токен із роллю `Read` у [своїх налаштуваннях](https://huggingface.co/settings/tokens).
3. Натисніть **Задати токен Hugging Face…** і вставте його.

Модель завантажується під час першого використання. Після цього мовці визначаються офлайн.

## Папка й Вивід

Показуються лише для папок:

- **Стежити за папкою**: див. [Стеження за папкою](/uk/guides/sources/#стеження-за-папкою).
- **Типи файлів**: для WhisperX — один або кілька з `.txt`, `.srt`, `.vtt`, `.json`, `.tsv` і `.aud`. Для Whisper API — формат файлів (`text`, `json`, `verbose_json`, `srt` або `vtt`); для субтитрів потрібна модель із часовими мітками. Google API повертає звичайний текст (`.txt`).
- **Розташування**: файли зберігаються поруч із кожним вихідним файлом. Натисніть **Змінити…**, щоб зберігати їх в іншу папку (її підпапки буде відтворено), або **Поруч із джерелом**, щоб повернутися.
- **Перезаписувати наявні файли**: знову транскрибує файли, які вже мають транскрипцію, і замінює її.

Параметри субтитрів (ширина рядка, кількість рядків, виділення слів) містяться в [Уподобаннях](/uk/reference/preferences/#субтитри).
