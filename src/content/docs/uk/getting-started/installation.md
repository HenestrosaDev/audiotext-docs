Audiotext — це настільний застосунок для **Windows**, **macOS** і **Linux**. Він перетворює на текст звук із файлів, відео з YouTube і записів із мікрофона, а також уміє перекладати його, створювати підсумки й субтитри.

## Завантажте застосунок

Завантажте файл для своєї системи з [останньої версії](https://github.com/HenestrosaDev/audiotext/releases/latest) на GitHub:

| Система | Файл |
| --- | --- |
| Windows (64-розрядна) | `Audiotext-<version>-windows-x64-setup.exe` |
| macOS 15 або новіша (Apple Silicon) | `Audiotext-<version>-macos-arm64.dmg` |
| Linux (x86_64) | `Audiotext-<version>-linux-x86_64.tar.gz` |

Застосунок містить усе необхідне, зокрема FFmpeg.

### Windows

Запустіть інсталятор і виконайте його кроки. Права адміністратора не потрібні. Якщо у вас є відеокарта NVIDIA, позначте варіант використання відеокарти NVIDIA (CUDA): тоді інсталятор завантажить GPU-доповнення, яке значно пришвидшує WhisperX. Інсталятор не підписано, тож Windows SmartScreen може показати попередження: відкрийте докладні відомості й виберіть запуск у будь-якому разі.

### macOS

Відкрийте файл `.dmg` і перетягніть **Audiotext** до папки **Програми**. Застосунок не засвідчено Apple, тож macOS блокує його під час першого відкриття: відкрийте **Системні параметри** → **Приватність і безпека** та натисніть **Усе одно відкрити** поруч із повідомленням про Audiotext. У macOS WhisperX працює на процесорі, бо CUDA там недоступна. Комп'ютери Mac із процесором Intel не підтримуються, бо PyTorch більше їх не підтримує.

### Linux

Розпакуйте архів і запустіть інсталятор у терміналі:

```bash
tar -xzf Audiotext-<version>-linux-x86_64.tar.gz
cd Audiotext-<version>-linux-x86_64
./install.sh
```

Він встановлює Audiotext для вашого користувача й додає його до меню застосунків (його також можна відкрити командою `audiotext`). Якщо він виявить відеокарту NVIDIA, то запропонує завантажити GPU-доповнення. Запустіть `./install.sh --gpu` або `./install.sh --cpu`, щоб вибрати без запитань, і `./install.sh --uninstall`, щоб видалити застосунок (налаштування зберігаються).

:::tip
GPU-доповнення важить близько 2 ГБ у Windows і 4 ГБ у Linux, тож воно має сенс лише з відеокартою NVIDIA. Без нього WhisperX працює на процесорі, а Whisper API і Google API працюють так само. Щоб пізніше перейти між версією для процесора і версією для GPU, установіть застосунок знову й виберіть інший варіант.
:::

:::note
Під час першої транскрипції за допомогою **WhisperX** (типового рушія) завантажується його модель. Її розмір — від ~75 МБ для `tiny` до ~3 ГБ для `large-v2`, тож це може тривати деякий час. Наступні транскрипції починаються одразу.
:::

## Вимоги

- **WhisperX** працює на вашому комп'ютері. Він працює на будь-якому процесорі, але значно швидше на відеокарті NVIDIA з CUDA. У розділі [Рушії](/uk/reference/engines/) можна підібрати модель для свого обладнання.
- **Whisper API** і **Google API** працюють на віддалених серверах, тож їм потрібне підключення до інтернету, але не потужне обладнання.
- Для транскрипції з мікрофона система має розпізнавати пристрій введення.
- У Linux для запису й відтворення потрібен [PortAudio](https://www.portaudio.com/) (`sudo apt install libportaudio2` в Ubuntu або Debian).

## Оновіть застосунок

Коли виходить нова версія, Audiotext показує на верхній панелі кнопку **Доступна версія …**. Натисніть її, щоб відкрити сторінку випуску, завантажте файл для своєї системи й установіть його так само, як уперше: у Windows запустіть новий інсталятор, у macOS перетягніть новий застосунок до теки **Програми**, а в Linux запустіть `install.sh` з нового архіву. Попередня версія замінюється, а ваші налаштування та історія зберігаються, бо вони зберігаються в [папці користувацької конфігурації](/uk/reference/files-and-data/#папка-користувацької-конфігурації). Якщо ви використовуєте доповнення для GPU, виберіть його знову під час установлення.

Щоб самостійно перевірити наявність нової версії, відкрийте **Уподобання** → **Про програму** → **Перевірити оновлення**. Щоб не перевіряти під час запуску застосунку, вимкніть **Загальні** → **Оновлення**.

## Змініть мову інтерфейсу

Audiotext використовує мову системи, якщо вона доступна. Щоб змінити її, відкрийте **Уподобання** (шестірня у правому верхньому куті) і виберіть мову в **Загальні** → **Мова інтерфейсу**.
