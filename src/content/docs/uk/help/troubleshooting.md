## Перша транскрипція з WhisperX триває довго

Під час першого використання модель завантажується, що може тривати кілька хвилин залежно від підключення й розміру моделі (до ~3 ГБ). Перебіг виконання показує, коли вона завантажується. Модель лишається в пам'яті, доки не змінюються її параметри, тож наступні транскрипції починаються одразу.

## WhisperX завершується помилкою `CUDA out of memory`

Відеокарті бракує пам'яті для цих налаштувань. Спробуйте по черзі:

1. Зменште **Розмір пакета** (наприклад, до `4`) в **Уподобання** → **WhisperX**.
2. Використовуйте меншу модель (наприклад, `small` або `base`).
3. Використовуйте легший **Тип обчислень** (наприклад, `int8`).

Останні два варіанти можуть знизити якість. Скільки пам'яті потрібно кожній моделі, вказано в розділі [Рушії](/uk/reference/engines/#модель).

## Транскрипція триває надто довго

Швидкість WhisperX залежить від обладнання, тож на слабких процесорах не варто чекати миттєвих результатів. Спробуйте меншу модель, наприклад `small`, `large-v3-turbo` на відеокарті або тип обчислень `int8`. Також можна використовувати **Whisper API** або **Google API**, які працюють на віддалених серверах.

## Whisper API повертає помилку `429`

```text
RateLimitError("Error code: 429 - {'error': {'message': 'You exceeded your current quota, ...', 'type': 'insufficient_quota', ...}}")
```

На вашому рахунку OpenAI закінчилися кошти, або перед першим використанням API його потрібно поповнити (навіть якщо у вас є безкоштовні кредити). Придбайте кредити в розділі [Billing](https://platform.openai.com/settings/organization/billing/overview) облікового запису OpenAI. Активація може тривати до 10 хвилин.

Якщо ви створили ключ API до першого поповнення й помилка не зникає через 10 хвилин, створіть новий ключ і задайте його в **Уподобання** → **Ключі API**.

## Мовці не визначаються

Для визначення мовців потрібен токен Hugging Face і прийняття умов моделі. Перевірте, що:

- Ви прийняли умови [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) з тим самим обліковим записом.
- Токен має роль `Read` і заданий в **Уподобання** → **Ключі API**.

Див. [Визначення мовців](/uk/guides/transcription-settings/#визначення-мовців).

## Мікрофон не знайдено або нічого не записується

- Перевірте, що мікрофон під'єднано, і натисніть кнопку оновлення поруч зі списком мікрофонів.
- У macOS дозвольте доступ для Audiotext у **Системні параметри** → **Приватність і безпека** → **Мікрофон**, у Windows — у **Настройки** → **Конфіденційність** → **Мікрофон**.
- Якщо індикатор рівня показує **Немає звуку**, виберіть інший мікрофон у списку або перевірте, чи не вимкнено звук.

## Аудіо транскрипції не відтворюється

Вихідний файл переміщено або видалено. Текст зберігається, але аудіо можна відтворити лише з вихідного файлу. Записи з мікрофона й аудіо за URL Audiotext зберігає сам.

## Відео з YouTube не завантажується

Перевірте, що URL правильний, а відео загальнодоступне. YouTube часто змінюється, тож, якщо помилка повторюється, перевірте, чи немає новішої версії Audiotext.

## Папка не транскрибує жодного файлу

Файли, які вже мають транскрипцію, пропускаються. Увімкніть **Перезаписувати наявні файли**, щоб транскрибувати їх знову. Папка також має містити [підтримувані файли](/uk/reference/formats-and-languages/).

## Google API запитує мову

Google API не вміє визначати мову. Виберіть **Мову аудіо** в налаштуваннях.
