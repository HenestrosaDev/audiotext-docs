## 오디오·동영상 형식

Audiotext는 FFmpeg로 동영상 파일에서 오디오를 추출하므로 둘 다 받아쓸 수 있습니다.

**오디오**: `.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**동영상**: `.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## 출력 형식

| 형식 | 내보내기 | 폴더(WhisperX) | 폴더(Whisper API) |
| --- | :---: | :---: | :---: |
| 일반 텍스트 (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Word 문서 (`.docx`) | ✓ | ✗ | ✗ |
| 자막 (`.srt`) | ✓ | ✓ | `srt` |
| 웹 자막 (`.vtt`) | ✓ | ✓ | `vtt` |
| 표 (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Audacity 라벨 (`.aud`) | ✗ | ✓ | ✗ |

[내보내기](/ko/guides/transcript/#복사와-내보내기)와 [출력 카드](/ko/guides/transcription-settings/#폴더와-출력)를 참고하세요.

## 인터페이스 언어

Audiotext의 인터페이스와 이 문서는 다음 언어로 제공됩니다.

| 언어 | | 언어 | |
| --- | --- | --- | --- |
| Català | 카탈루냐어 | Polski | 폴란드어 |
| Čeština | 체코어 | Português | 포르투갈어 |
| Deutsch | 독일어 | Română | 루마니아어 |
| English | 영어 | Русский | 러시아어 |
| Español | 스페인어 | Svenska | 스웨덴어 |
| Français | 프랑스어 | Türkçe | 터키어 |
| Galego | 갈리시아어 | Українська | 우크라이나어 |
| हिन्दी | 힌디어 | Tiếng Việt | 베트남어 |
| Bahasa Indonesia | 인도네시아어 | 简体中文 | 중국어(간체) |
| Italiano | 이탈리아어 | 日本語 | 일본어 |
| Nederlands | 네덜란드어 | 한국어 | 한국어 |

**환경설정** → **일반** → **인터페이스 언어**에서 바꿉니다. 번역을 개선하거나 언어를 추가하려면 [기여하기](/ko/help/contributing/#인터페이스-번역)를 참고하세요.
