받아쓰기가 완료되면 Audiotext는 언어 모델이나 번역 서비스로 요약하고, 그에 관한 질문에 답하고, 번역할 수 있습니다. 모두 기록에 저장되므로 한 번만 생성됩니다.

## 요약

받아쓰기의 **요약** 모드를 열고 **요약 생성**을 클릭합니다. 언어 모델이 다음을 작성합니다.

- 받아쓰기의 **요약**.
- **핵심 내용**.
- 타임스탬프가 있으면 **챕터**. 챕터를 클릭하면 그 시작 지점부터 오디오를 재생합니다.

제목 아래에는 요약을 생성한 모델과 시각이 표시됩니다. 머리글의 버튼:

- **찾기**(`Ctrl+F`, macOS에서는 `⌘F`): 요약에서 텍스트를 찾습니다.
- **복사**: 요약을 복사합니다.
- **내보내기**: 요약만 일반 텍스트, Markdown, Word 문서로 저장합니다. 받아쓰기를 덮어쓰지 않도록 `video.summary.md` 같은 이름이 붙습니다. 받아쓰기의 Markdown과 Word [내보내기](/ko/guides/transcript/#복사와-내보내기)에도 포함됩니다.
- **요약 다시 생성**: 요약을 다시 씁니다(예: 다른 모델을 고른 뒤). 현재 요약이 바뀌므로 먼저 확인합니다.

제공자의 API 키가 설정되지 않았다면 **요약** 모드에서 설정하도록 안내합니다. 매우 긴 받아쓰기(약 3시간 이상의 발화)는 앞부분만 요약합니다.

## 받아쓰기에 대해 질문하기

**질문** 모드를 열고 **받아쓰기에 대해 질문하기…**에 질문을 입력한 다음(예: 무엇이 결정되었는지, 누가 무슨 말을 했는지) `Enter`를 누르거나 **질문**을 클릭하세요.

- 언어 모델은 받아쓰기와 이전 질문 및 답변을 바탕으로 답하므로, 앞의 질문을 이어서 물어볼 수 있습니다(예: “왜?”).
- 받아쓰기에 타임스탬프가 있으면 각 답변에 그 내용이 나오는 부분으로 가는 링크가 붙습니다. 클릭하면 그 위치부터 오디오를 재생합니다.
- 질문과 답변은 받아쓰기와 함께 기록에 저장됩니다. 머리글의 휴지통은 확인 후 대화를 지웁니다.

질문에는 **환경설정** → **AI** → **질문**에서 고른 제공자가 답하며, 바꾸기 전까지는 요약의 제공자와 같습니다. 요약과 마찬가지로 아주 긴 받아쓰기는 앞부분만 읽습니다.

## 번역

**번역**을 클릭하고 **번역할 언어:**에서 언어를, **번역 방법:**에서 제공자를 고른 다음 확인합니다. 대화 상자에는 고른 제공자가 무엇을 하는지 표시되며, API 키가 없으면 설정하도록 안내합니다. 번역은 원본 텍스트 오른쪽 패널에 표시됩니다.

- 받아쓰기에 타임스탬프가 있으면 각 부분의 앞뒤에 말한 내용을 맥락으로 삼아 문장 단위로 번역되므로, 번역은 각 문장의 타임스탬프로 시작합니다. 재생 중인 문장이 강조되고, 문장을 클릭하면 재생됩니다.
- 일반 텍스트를 편집했다면 편집한 텍스트가 타임스탬프 없이 번역됩니다.
- 두 텍스트는 함께 스크롤되어 오디오의 같은 부분을 보여 줍니다. 사이에 있는 핸들의 둥근 버튼으로 켜고 끕니다. 핸들을 끌어 크기를 조절하고, 더블클릭하면 원래 크기로 돌아갑니다.

번역 머리글의 버튼으로 찾기 및 바꾸기, 복사, 내보내기, **다시 번역**(같은 제공자와 모델로), **번역 숨기기**를 할 수 있습니다. **번역** 버튼에서 다시 표시하거나, **다른 언어로 번역…**, **번역 삭제**도 할 수 있습니다.

### 여러 언어

받아쓰기는 여러 언어로, 동시에도 번역할 수 있으며 각 번역이 보관됩니다. 패널 제목에서 표시할 번역을 고를 수 있고, 각 번역이 얼마나 진행되었는지 보여 주며, 마지막에 다른 언어로 번역하는 옵션이 있습니다. 이미 번역이 있는 언어로 번역하면 그 수정 내용이 사라지므로 확인 후 바꿉니다.

### 번역 수정과 타이밍 조정

번역은 원본과 다른 타이밍이 필요할 때가 많습니다(예: 읽는 데 더 오래 걸리는 자막). 번역의 세그먼트를 마우스 오른쪽 버튼으로 클릭해 다음을 할 수 있습니다.

- **텍스트 편집…**: 텍스트를 바꿉니다.
- **타이밍 편집…**: 시작과 끝 시간을 밀리초 단위로 바꿉니다. 시간은 `00:01:05,900`, `01:05,9`, `65.9`처럼 입력합니다.
- **뒤에 세그먼트 추가…**: 세그먼트를 추가합니다. 기본적으로 다음 세그먼트까지의 빈 시간을 채웁니다.
- **세그먼트 삭제**.

### 직접 번역하기

번역을 직접 쓰려면 **번역 방법:**에서 **수동**을 고르세요. API 키가 필요 없습니다. 번역은 받아쓰기의 자막마다 빈 세그먼트(**아직 번역되지 않음**으로 표시)로 시작하고, 패널에 남은 개수가 표시됩니다. 세그먼트를 마우스 오른쪽 버튼으로 클릭하고 **텍스트 번역…**을 고르면, 그동안 말한 원본 텍스트가 대화 상자에 표시됩니다.

### 자막과 내보내기

- 동영상 받아쓰기에서 **번역** 메뉴의 **동영상 자막으로 표시**를 켜면 번역을 자막으로 보여 줍니다. 동영상 메뉴에서도 바꿀 수 있습니다. [자막과 함께 동영상 보기](/ko/guides/transcript/#자막과-함께-동영상-보기)를 참고하세요.
- 번역을 파일로 저장하려면 그 패널의 내보내기 버튼을 클릭하세요. 받아쓰기와 같은 [형식](/ko/guides/transcript/#복사와-내보내기)으로, 파일 이름에 언어를 넣어(예: `video.es.srt`) 내보내므로 동영상 플레이어가 동영상과 함께 불러옵니다. 아직 번역되지 않은 세그먼트는 자막에서 빠집니다. 같은 메뉴에서 [자막이 있는 동영상 사본](/ko/guides/transcript/#자막이-있는-동영상-내보내기)도 만들 수 있습니다.

:::tip
제공자 없이 다른 언어로 바로 받아쓰기를 얻으려면 받아쓰는 동안 번역할 수도 있습니다. [언어](/ko/guides/transcription-settings/#언어)를 참고하세요.
:::

## 제공자

제공자는 **환경설정** → **AI**에서 요약, 질문, 번역 각각에 대해 고릅니다.

| 제공자 | 기본 모델 | API 키 |
| --- | --- | --- |
| OpenAI(기본값) | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude(Anthropic) | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini(Google) | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama(로컬) | `llama3.2` | 필요 없음 |

**모델**을 비워 두면 제공자의 기본 모델을 사용합니다. 제공자의 다른 모델 이름을 입력할 수도 있습니다(예: `claude-sonnet-5-5`, `deepseek-reasoner`).

번역은 다음 서비스로도 할 수 있습니다.

- **DeepL**: [DeepL API 키](https://www.deepl.com/your-account/keys)가 필요합니다. 무료 요금제 키도 작동합니다.
- **Google Translate**: Cloud Translation API가 활성화된 Google API 키를 사용합니다.

### Ollama

[Ollama](https://ollama.com)는 API 키 없이, 텍스트를 어디에도 보내지 않고 내 컴퓨터에서 모델을 실행합니다. 설치하고 모델을 다운로드한 다음(예: `ollama pull llama3.2`) 제공자로 **Ollama**를 고르세요. 기본 주소에서 실행되지 않는다면 **환경설정** → **AI**의 **서버 URL**을 바꾸세요(기본값 `http://localhost:11434`).

:::note
각 제공자는 API 사용 요금을 청구하며, Audiotext는 이에 대해 책임지지 않습니다. API 키는 시스템의 자격 증명 저장소에 보관됩니다. [파일과 데이터](/ko/reference/files-and-data/)를 참고하세요.
:::
