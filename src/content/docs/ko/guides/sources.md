Audiotext는 네 가지 소스에서 받아쓰며, 상단 바의 **새 받아쓰기**에서 소스를 고릅니다.

## 파일

오디오 또는 동영상 파일을 받아씁니다. **파일 선택…**을 클릭하거나 파일을 창에 끌어다 놓으세요. 파일 탐색기는 기본적으로 **지원되는 모든 파일**을 표시하며, **오디오 파일**이나 **동영상 파일**만 표시할 수도 있습니다. 지원 형식은 [형식과 언어](/ko/reference/formats-and-languages/)를 참고하세요.

한 번에 파일 하나만 추가할 수 있습니다. 여러 파일을 받아쓰려면 [폴더](#폴더) 소스를 사용하세요.

## URL

**YouTube 동영상**이나 **오디오·동영상 파일 직접 링크**(예: 팟캐스트 에피소드)를 받아씁니다. URL을 붙여넣고(**붙여넣기** 또는 `Ctrl+V`) **계속**을 클릭합니다. URL은 `http://` 또는 `https://`로 시작해야 합니다.

```text
https://youtu.be/dQw4w9WgXcQ
https://example.com/podcast/episode-12.mp3
```

먼저 오디오를 다운로드하므로 인터넷 연결이 필요합니다.

## 마이크

내 목소리나 회의를 녹음하고 받아씁니다. 녹음은 기록에 남으므로 나중에 다시 재생할 수 있습니다.

1. 목록에서 마이크를 고릅니다(방금 연결했다면 새로 고침 버튼을 클릭하세요).
2. 녹음 버튼을 클릭해(또는 `Ctrl+Enter`, macOS에서는 `⌘↩`) 녹음을 시작합니다. 레벨 미터가 소리가 너무 작은지, **적절한 수준**인지, 너무 큰지 알려 줍니다.
3. 다시 클릭하면 녹음을 멈추고 받아씁니다.

### 실시간 텍스트

**WhisperX**를 사용할 때 **실시간 텍스트** 카드에서 **녹음 중 텍스트 표시**를 켜면 말하는 동안 텍스트 초안을 볼 수 있습니다. 초안은 빠른 **실시간 모델**(기본값 `small`)이 작성합니다. 녹음을 멈추면 전체 녹음을 더 정확한 엔진 모델로 다시 받아쓰고 초안을 대체합니다.

![마이크로 녹음하는 동안의 실시간 텍스트](/screenshots/live-text.png)

:::caution
시스템이 입력 장치를 인식하고 앱의 사용을 허용해야 합니다. 그렇지 않으면 **마이크를 찾을 수 없습니다**라는 메시지가 표시됩니다. macOS에서는 **시스템 설정** → **개인정보 보호 및 보안** → **마이크**에서 Audiotext를 허용하세요.
:::

### 컴퓨터 오디오 녹음하기

컴퓨터에서 재생되는 소리(화상 통화, 웨비나, 다운로드할 수 없는 동영상 등)를 텍스트로 변환하려면 스피커의 소리를 입력으로 보내는 장치에서 녹음하세요. 한 번 설정한 후 새로 고침 버튼을 클릭하고 마이크 목록에서 선택하면 됩니다. 컴퓨터에서 재생되는 모든 소리가 알림음까지 녹음되지만, 내 목소리는 녹음되지 않습니다.

- **Windows**: `mmsys.cpl`을 실행하고 **녹음** 탭에서 목록을 마우스 오른쪽 버튼으로 클릭해 사용 안 함 장치를 표시한 다음 **스테레오 믹스**를 사용으로 설정하세요. 사운드 카드에 없다면 [VB-CABLE](https://vb-audio.com/Cable/)을 설치하고 **CABLE Input**을 출력 장치로 설정한 뒤 Audiotext에서 **CABLE Output**을 선택하세요. 소리를 계속 들으려면 **CABLE Output**의 속성에서 **이 장치로 듣기**를 선택하세요.
- **macOS**: [BlackHole](https://existential.audio/blackhole/)을 설치하고(`brew install blackhole-2ch`) Audiotext에서 **BlackHole 2ch**를 선택하세요. 소리를 계속 들으려면 스피커와 BlackHole로 [다중 출력 기기](https://github.com/ExistentialAudio/BlackHole/wiki/Multi-Output-Device)를 만들어 출력 장치로 설정하세요.
- **Linux**(PulseAudio 또는 PipeWire): Audiotext에서 **pulse**를 선택하고 녹음을 시작하세요. 그런 다음 `pavucontrol`의 **녹음** 탭에서 Audiotext의 소스를 스피커의 모니터로 바꾸세요.

## 폴더

폴더의 모든 오디오 및 동영상 파일을 받아씁니다. **폴더** 카드에서 **하위 폴더 포함**가 켜져 있으면 하위 폴더의 파일도 받아씁니다. **폴더 선택…**를 클릭하거나 폴더를 창에 끌어다 놓으세요. Audiotext가 찾은 파일 수를 알려 줍니다. 일부 파일을 제외하려면 **다음과 일치하는 파일 건너뛰기**에 해당 파일의 이름이나 경로를 쉼표로 구분해 입력합니다(예: `*.wav, drafts/*`). 숨김 파일은 항상 건너뜁니다.

각 파일의 받아쓰기는 파일 옆(또는 **출력** 카드에서 고른 다른 폴더)에 같은 이름과 선택한 각 **파일 형식**의 확장자로 저장됩니다. 예를 들어 `.txt`와 `.vtt`를 고르면 다음과 같습니다.

```text
files-to-transcribe
├── paranoid-android.mp3
├── paranoid-android.txt
├── paranoid-android.vtt
└── movies
    ├── mulholland-dr.avi
    ├── mulholland-dr.txt
    └── mulholland-dr.vtt
```

두 파일의 이름이 같고 확장자가 다르면(예: `talk.mp3`와 `talk.mp4`) 서로 덮어쓰지 않도록 받아쓰기 파일 이름에 확장자가 유지됩니다(`talk.mp3.txt`와 `talk.mp4.txt`).

이미 받아쓰기가 있는 파일은 **건너뜁니다**. 파일은 선택한 파일 형식이 모두 있을 때만 건너뛰므로, 파일 형식을 추가하면 다시 받아씁니다. 받아쓸 수 없는 파일이 있어도 나머지 파일은 계속 받아씁니다.

### 폴더의 파일

기록에 있는 폴더 페이지에는 폴더의 파일이 각각의 상태, 길이, 크기, 텍스트 미리 보기와 함께 표시됩니다. 파일을 검색하고, 상태(**전체**, **완료**, **실패**, **대기 중**)로 필터링하고, 이름, 상태, 길이, 크기순으로 정렬할 수 있습니다. 이동되거나 삭제된 파일은 **파일을 찾을 수 없음**으로 표시됩니다.

- 파일을 클릭하면 받아쓰기가 열립니다. 파일의 `⋯` 버튼을 클릭하거나 파일을 마우스 오른쪽 버튼으로 클릭하면 텍스트를 복사하거나, 내보내기·요약·번역을 바로 열거나, 파일 관리자에서 보거나, **이 파일 다시 받아쓰기**를 할 수 있습니다.
- `Ctrl`/`⌘` 또는 `Shift`로 여러 파일을 선택하거나 `Ctrl+A` / `⌘A`로 표시된 파일을 모두 선택한 다음, **다시 받아쓰기**, **내보내기…**(하나의 TXT, Markdown 또는 Word 파일로 함께), **기록에서 제거…**를 할 수 있습니다. `Enter`는 선택한 파일을 열고, `Esc`는 선택을 해제합니다.
- **실패한 항목 다시 시도**는 실패한 파일을 다시 받아씁니다. **폴더 다시 검색**는 새 파일처럼 받아쓰기가 없는 파일만 받아쓰고, 이미 받아쓰기가 있어서 건너뛴 파일 수를 알려 줍니다.
- 폴더의 `⋯` 메뉴에서는 **모두 다시 받아쓰기…**(모든 파일을 다시 받아쓰고 받아쓰기를 교체), **모두 내보내기…**(하나의 파일로), 없는 파일을 목록에서 제거, 원본 폴더나 저장된 파일의 폴더 열기를 할 수 있습니다.
- 폴더 설정을 바꾸면 다른 설정(엔진, 모델, 언어 등)으로 받아쓴 파일이 **다시 받아쓰기** 버튼과 함께 표시됩니다.

머리글에는 파일이 저장되는 위치와 원본 폴더 링크가 표시됩니다. **설정 편집**로 폴더 설정을 바꾸고, **저장하고 다시 검색**로 그 설정을 사용해 받아쓰기가 없는 파일을 받아씁니다.

### 폴더 감시

**폴더** 카드에서 **폴더 감시**를 켜면 **감시 중지**를 클릭할 때까지 폴더(또는 하위 폴더)에 추가되는 파일을 계속 받아씁니다. 음성 녹음기나 회의 도구의 녹음이 폴더로 복사될 때 유용합니다.

- 폴더에 이미 있는 파일은 건너뜁니다. 단, **폴더에 이미 있는 파일 받아쓰기**를 켜면 받아쓰기가 없는 파일을 먼저 받아씁니다.
- 파일은 복사가 완전히 끝난 뒤(크기가 더 이상 바뀌지 않을 때) 받아쓰므로 큰 파일이 중간까지만 받아써지지 않습니다.
- Audiotext를 닫을 때 감시 중이던 폴더는 다시 열 때 이미 확인한 파일 다음부터 다시 감시됩니다. 중지된 폴더는 **감시 재개**로 다시 감시할 수 있습니다.
- 폴더를 사용할 수 없으면(예: 연결되지 않은 드라이브에 있는 경우) Audiotext는 실패하지 않고 폴더를 기다립니다.
- 다른 것을 받아쓰거나 녹음하려면 폴더 감시가 일시 중지되고(그때까지 새 받아쓰기에는 **시작하는 중…**가 표시됨), 끝나면 다시 감시됩니다.
- 오류가 발생해도 감시는 멈추지 않으며, 함께 받아쓴 파일은 하나의 알림으로 알려 줍니다.

## 대기열

다른 받아쓰기가 진행 중일 때도 새 받아쓰기를 설정할 수 있습니다. 버튼이 **대기열에 추가**로 바뀌고 현재 작업이 끝나면 시작됩니다. 대기 중이거나 진행 중인 받아쓰기는 기록에 표시됩니다.
