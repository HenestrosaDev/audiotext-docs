[기록](/ko/guides/history/)에서 받아쓰기를 선택하면 열립니다. 도구 모음에서 **대본**, **일반 텍스트**, **요약** 세 가지 모드를 전환할 수 있고, **번역**, **복사**, **내보내기** 버튼이 있습니다.

## 대본 모드

받아쓰기의 각 세그먼트(한 문장 또는 긴 문장의 일부)를 시작과 끝 시간과 함께 보여 주고, 화자를 식별했다면 화자도 표시합니다.

기본적으로 시간은 간단하게 표시됩니다(`01:05 – 01:09`). 자막처럼 밀리초 단위로 보려면(`00:01:05,900 – 00:01:09,350`) `⋯` 메뉴에서 **정밀한 타임스탬프 (00:00:01,000)**를 켜세요.

타임스탬프는 **WhisperX**와 **Whisper API**의 `whisper-1`, `gpt-4o-transcribe-diarize` 모델에서만 제공됩니다. 타임스탬프가 없으면 세그먼트 단위로 재생할 수 없으므로 **일반 텍스트** 모드를 사용하세요.

### 오디오 재생

- **세그먼트를 클릭**하면 그 위치부터 오디오를 재생합니다. 재생 중인 세그먼트가 강조되고 텍스트가 재생을 따라갑니다. 단어별 타이밍이 있으면 각 단어도 강조됩니다.
- 플레이어 바로 재생, 일시 정지, 원하는 위치로 이동, **속도** 변경(`0.5×`~`2×`, 목소리 높낮이 유지)을 할 수 있습니다.
- 키보드 단축키: `Space`로 재생·일시 정지, `←`/`→`로 5초 뒤로·앞으로.

원본 파일을 옮기거나 삭제했다면 오디오는 사용할 수 없지만 텍스트는 남습니다. 마이크 녹음은 Audiotext가 보관하므로 언제든 재생할 수 있습니다.

### 자막과 함께 동영상 보기

동영상 받아쓰기에서는 텍스트 위에 동영상이 표시됩니다. 메뉴에서 **동영상에 자막 표시**를 켜고 자막의 **크기**(작게, 중간, 크게), **위치**(아래, 위), **스타일**(어두운 배경, 외곽선)을 고를 수 있습니다. 받아쓰기에 [번역](/ko/guides/summary-and-translation/#번역)이 있으면 자막에 **받아쓰기**와 번역 중 무엇을 표시할지도 이 메뉴에서 고릅니다.

### 검색

`Ctrl+F`(macOS에서는 `⌘F`)를 누르고 입력합니다. `Enter`와 `Shift+Enter`로 다음·이전 결과로 이동하고 `Esc`로 검색을 지웁니다.

## 받아쓰기 수정

자막과 재생에 쓰이는 타임스탬프를 유지하면서 받아쓰기를 고치려면 `⋯` 메뉴의 옵션을 쓰거나 세그먼트를 마우스 오른쪽 버튼으로 클릭하세요.

- **찾기 및 바꾸기…**: 받아쓰기 전체에서 단어나 구문을 바꿉니다(예: 철자가 틀린 이름). 바꾸기 전에 텍스트가 몇 번 나오는지 보여 주며 **대/소문자 구분**도 할 수 있습니다.
- **화자 이름 바꾸기…**: 각 화자에게 이름을 붙입니다(`SPEAKER_00` → `지민`). 두 화자에게 같은 이름을 붙이면 하나로 합쳐집니다.
- **텍스트 편집…**: 세그먼트를 마우스 오른쪽 버튼으로 클릭해 텍스트를 바꿉니다.
- **여기부터 재생**: 세그먼트를 마우스 오른쪽 버튼으로 클릭해 재생합니다.

바뀌지 않은 단어는 타이밍을 유지하므로 재생 중에도 계속 강조됩니다.

## 일반 텍스트

**일반 텍스트** 모드에서는 텍스트 편집기처럼 자유롭게 텍스트를 고칠 수 있습니다. 변경 사항은 자동으로 저장됩니다. 대본은 원래 텍스트와 타임스탬프를 유지하므로 자막에는 일반 텍스트의 수정 내용이 반영되지 않습니다.

## 복사와 내보내기

**복사**는 현재 모드의 텍스트(대본, 요약, 번역)를 복사합니다.

**내보내기**(또는 `Ctrl+S`, macOS에서는 `⌘S`)는 받아쓰기를 다음 형식으로 저장합니다.

| 형식 | 내용 |
| --- | --- |
| 일반 텍스트 (`.txt`) | 텍스트 |
| Markdown (`.md`) | 요약(있는 경우)과 단락별 타임스탬프 및 화자가 포함된 텍스트 |
| Word 문서 (`.docx`) | Markdown과 같은 내용으로, 편집하거나 인쇄할 수 있습니다 |
| 자막 (`.srt`) | 동영상 플레이어용 자막 |
| 웹 자막 (`.vtt`) | 웹용 자막 |
| 표 (`.tsv`) | 세그먼트마다 한 줄, 시작과 끝(밀리초)과 텍스트 |
| JSON (`.json`) | 텍스트, 타임스탬프·단어·화자가 포함된 구간, 요약(있는 경우) |

자막과 표에는 타임스탬프가 필요합니다.

받아쓰기에 번역이 있으면 같은 메뉴에서 **번역(…)**을 고르거나 번역의 내보내기 버튼을 클릭해 번역을 같은 형식으로 내보낼 수 있습니다. 파일 이름에 언어가 들어가므로(예: `video.es.srt`) 동영상 플레이어가 동영상과 함께 불러옵니다.

## 이름 변경, 태그, 메모

받아쓰기 머리글에는 이름, 소스, 날짜, 태그가 표시됩니다. 이름을 더블클릭하면 이름을 바꾸고, 태그를 클릭하면 태그를 바꾸고, **메모 추가**를 클릭하면 메모를 쓸 수 있습니다. 메모나 연필을 클릭하면 편집하고, 휴지통을 클릭하면 삭제합니다. 다른 옵션은 [기록](/ko/guides/history/)에 있습니다.
