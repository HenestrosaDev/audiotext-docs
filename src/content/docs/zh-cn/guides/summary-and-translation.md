转写完成后，Audiotext 可以用语言模型或翻译服务为其生成摘要、回答有关它的问题并翻译它。这些内容都会保存在历史记录中，因此只需生成一次。

## 摘要

打开转写的**摘要**模式，点击**生成摘要**。语言模型会写出：

- 转写的**摘要**。
- **要点**。
- 如果有时间戳，还会生成**章节**。点击章节即可从其开头播放音频。

面板标题下方会显示生成摘要的模型和时间。其标题栏中的按钮：

- **查找**（`Ctrl+F`，macOS 上为 `⌘F`）：在摘要中查找文本。
- **复制**：复制摘要。
- **导出**：将摘要单独保存为纯文本、Markdown 或 Word 文档，文件名类似 `video.summary.md`，以免覆盖转写。转写的 Markdown 和 Word [导出](/zh-cn/guides/transcript/#复制与导出)中也会包含它。
- **重新生成摘要**：重写摘要（例如更换模型之后），会先询问你，因为当前摘要会被替换。

如果尚未设置提供商的 API 密钥，**摘要**模式会提示你设置。非常长的转写（约三小时或更长的讲话）只会对开头部分生成摘要。

## 就转写提问

打开**提问**模式，在**就转写内容提问…**中输入问题（例如做出了什么决定，或谁说了什么），然后按 `Enter` 或点击**提问**。

- 语言模型会根据转写以及之前的问题和回答来作答，因此问题可以承接之前的内容（例如“为什么？”）。
- 如果转写有时间戳，每个回答都会链接到转写中说到相关内容的部分。点击其中一个即可从该处播放音频。
- 问题和回答会随转写一起保存在历史记录中。标题栏中的垃圾桶会在询问你之后清除对话。

问题由在**偏好设置** → **AI** → **提问**中为其选择的提供商回答；在你更改之前，它就是摘要的提供商。与摘要一样，非常长的转写只会读取开头部分。

## 翻译

点击**翻译**，在**翻译成：**中选择语言，在**翻译方式：**中选择提供商，然后确认。对话框会说明所选提供商的作用，如果缺少 API 密钥还会提示你设置。译文会显示在原文右侧的面板中。

- 如果转写有时间戳，会逐句翻译，并以每部分前后所说的文本作为上下文，因此译文以每个句子的时间戳开始：会高亮正在播放的句子，点击句子即可播放。
- 如果你编辑过纯文本，则会翻译编辑后的文本，且没有时间戳。
- 两段文本会一起滚动，因此显示音频的同一部分。它们之间分隔条上的圆形按钮可开启或关闭此功能。拖动分隔条可调整大小，双击可恢复默认大小。

翻译标题栏中的按钮可以在其中查找和替换、复制、导出、**重新翻译**（使用相同的提供商和模型）以及**隐藏翻译**。**翻译**按钮还可以重新显示它、**翻译成其他语言…**或**删除翻译**。

### 多种语言

一个转写可以翻译成多种语言，甚至同时进行，每个翻译都会保留。面板标题可选择要显示的翻译，显示每个翻译完成了多少，并以翻译成其他语言的选项结尾。翻译成已有翻译的语言会在询问你之后替换它，因为其校对内容将会丢失。

### 校对译文并调整时间

译文通常需要与原文不同的时间，例如需要更长阅读时间的字幕。右键点击译文的某个片段，可以：

- **编辑文本…**：修改其文本。
- **编辑时间…**：精确到毫秒地修改其开始和结束时间。时间可输入为 `00:01:05,900`、`01:05,9` 或 `65.9`。
- **在后面添加片段…**：添加一个片段，默认填满到下一个片段之间的空隙。
- **删除片段**。

### 自己翻译

要自己撰写译文，请在**翻译方式：**中选择**手动**。无需 API 密钥。译文以转写每条字幕对应的空白片段开始，空白片段显示为**尚未翻译**，面板会显示剩余数量。右键点击其中一个并选择**翻译文本…**：对话框会显示这段时间内所说的原文。

### 字幕与导出

- 在视频的转写中，于**翻译**菜单勾选**显示为视频字幕**，即可将译文显示为字幕。视频的菜单也可以切换。参见[带字幕观看视频](/zh-cn/guides/transcript/#带字幕观看视频)。
- 要将译文保存为文件，请点击其面板中的导出按钮。它会以与转写相同的[格式](/zh-cn/guides/transcript/#复制与导出)导出，文件名包含其语言（例如 `video.es.srt`），因此视频播放器会随视频一起加载它。尚未翻译的片段不会包含在字幕中。同一菜单还可以生成[带字幕的视频副本](/zh-cn/guides/transcript/#导出带字幕的视频)。

:::tip
若想不借助提供商直接得到另一种语言的转写，也可以在转写时进行翻译。请参阅[语言](/zh-cn/guides/transcription-settings/#语言)。
:::

## 提供商

提供商在**偏好设置** → **AI** 中选择，摘要、提问和翻译分别设置。

| 提供商 | 默认模型 | API 密钥 |
| --- | --- | --- |
| OpenAI（默认） | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude（Anthropic） | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini（Google） | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama（本地） | `llama3.2` | 不需要 |

将**模型**留空即使用提供商的默认模型，也可以输入该提供商的其他模型名称（例如 `claude-sonnet-5-5` 或 `deepseek-reasoner`）。

翻译还可以使用：

- **DeepL**，需要 [DeepL API 密钥](https://www.deepl.com/your-account/keys)。免费套餐的密钥也可以使用。
- **Google Translate**，使用已启用 Cloud Translation API 的 Google API 密钥。

### Ollama

[Ollama](https://ollama.com) 在你的电脑上运行模型，无需 API 密钥，也不会把文本发送到任何地方。安装它，下载一个模型（例如 `ollama pull llama3.2`），然后选择 **Ollama** 作为提供商。如果它没有运行在默认地址上，请在**偏好设置** → **AI** 中修改**服务器 URL**（默认为 `http://localhost:11434`）。

:::note
各提供商会对其 API 的使用收费，Audiotext 对此不承担责任。API 密钥保存在系统的凭据存储中。请参阅[文件与数据](/zh-cn/reference/files-and-data/)。
:::
