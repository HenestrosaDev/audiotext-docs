Audiotext 支持四种来源，可在顶部栏的**新转写**中选择。

## 文件

转写一个音频或视频文件。点击**选择文件…**，或把文件拖放到窗口中。文件浏览器默认显示**所有支持的文件**，你也可以只显示**音频文件**或**视频文件**。支持的格式请参阅[格式与语言](/zh-cn/reference/formats-and-languages/)。

一次只能添加一个文件。要转写多个文件，请使用[文件夹](#文件夹)来源。

## URL

转写 **YouTube 视频**或**指向音频或视频文件的直链**（例如某期播客）。粘贴 URL（使用**粘贴**或 `Ctrl+V`），然后点击**继续**。URL 必须以 `http://` 或 `https://` 开头。

```text
https://youtu.be/dQw4w9WgXcQ
https://example.com/podcast/episode-12.mp3
```

会先下载音频，因此需要联网。

## 麦克风

录制你的声音或会议并进行转写。录音会保存在历史记录中，方便以后播放。

1. 在列表中选择麦克风（如果刚刚连接，请点击刷新按钮）。
2. 点击录音按钮（或按 `Ctrl+Enter`，macOS 上为 `⌘↩`）开始录音。电平表会提示声音太小、**音量合适**还是太大。
3. 再次点击即可停止并转写。

### 实时文本

使用 **WhisperX** 时，在**实时文本**卡片中打开**录音时显示文本**，即可在说话时看到文本草稿。草稿由快速的**实时模型**生成（默认为 `small`）。停止后，整段录音会用更准确的引擎模型重新转写，并替换草稿。

![使用麦克风录音时的实时文本](/screenshots/live-text.png)

:::caution
系统必须能识别输入设备，并允许应用使用它。否则会显示**未找到麦克风**。在 macOS 上，请在**系统设置** → **隐私与安全性** → **麦克风**中允许 Audiotext。
:::

## 文件夹

转写文件夹**及其子文件夹**中的所有音频和视频文件。点击**选择文件夹…**，或把文件夹拖放到窗口中。Audiotext 会显示找到的文件数量。

每个文件的转写会保存在该文件旁边（或保存到你在**输出**卡片中选择的其他文件夹），文件名相同，扩展名为所选的每种**文件类型**。例如选择 `.txt` 和 `.vtt` 时：

```text
files-to-transcribe
├── paranoid-android.mp3
├── paranoid-android.txt
├── paranoid-android.vtt
└── movies
    ├── mulholland-dr.avi
    ├── mulholland-dr.txt
    └── mulholland-dr.vtt
```

已有转写的文件会被**跳过**，除非你打开**覆盖现有文件**。因此，向文件夹中添加一个文件后再次转写，只会转写这个新文件。

如果某个文件无法转写，其余文件仍会继续转写，文件夹视图会显示哪些失败及原因。**重新转写**会重新处理文件夹，文件夹按钮会打开保存文件的文件夹。

### 监视文件夹

在**文件夹**卡片中打开**监视文件夹**，即可持续转写添加到该文件夹（或其子文件夹）的文件，直到你点击**停止监视**。这适合录音笔或会议工具把录音复制到某个文件夹的场景。

- 文件夹中已有的文件会被跳过。要转写它们，请在不监视的情况下转写该文件夹。
- 文件在完全复制后（大小不再变化时）才会被转写，因此大文件不会只转写一半。
- 出错不会停止监视。

## 队列

在另一个转写进行时，你也可以设置新的转写：按钮会变为**添加到队列**，当前转写完成后开始。排队中和进行中的转写会显示在历史记录中。
