Audiotext 支持四种来源，可在顶部栏的**新转写**中选择。

## 文件

转写一个音频或视频文件。点击**选择文件…**，或把文件拖放到窗口中。文件浏览器默认显示**所有支持的文件**，你也可以只显示**音频文件**或**视频文件**。支持的格式请参阅[格式与语言](/zh-cn/reference/formats-and-languages/)。

一次只能添加一个文件。要转写多个文件，请使用[文件夹](#文件夹)来源。

## URL

转写 **YouTube 视频**或**指向音频或视频文件的直链**（例如某期播客）。粘贴 URL（使用**粘贴**或 `Ctrl+V`），然后点击**继续**。URL 必须以 `http://` 或 `https://` 开头。

```text
https://youtu.be/dQw4w9WgXcQ
https://example.com/podcast/episode-12.mp3
```

会先下载音频，因此需要联网。

## 麦克风

录制你的声音或会议并进行转写。录音会保存在历史记录中，方便以后播放。

1. 在列表中选择麦克风（如果刚刚连接，请点击刷新按钮）。
2. 点击录音按钮（或按 `Ctrl+Enter`，macOS 上为 `⌘↩`）开始录音。电平表会提示声音太小、**音量合适**还是太大。
3. 再次点击即可停止并转写。

### 实时文本

使用 **WhisperX** 时，在**实时文本**卡片中打开**录音时显示文本**，即可在说话时看到文本草稿。草稿由快速的**实时模型**生成（默认为 `small`）。停止后，整段录音会用更准确的引擎模型重新转写，并替换草稿。

![使用麦克风录音时的实时文本](/screenshots/live-text.png)

:::caution
系统必须能识别输入设备，并允许应用使用它。否则会显示**未找到麦克风**。在 macOS 上，请在**系统设置** → **隐私与安全性** → **麦克风**中允许 Audiotext。
:::

### 录制电脑播放的音频

要转写电脑正在播放的内容（视频通话、网络研讨会、无法下载的视频），请从一个把扬声器声音送到输入端的设备录音。只需设置一次，然后点击刷新按钮，并在麦克风列表中选择它。电脑播放的所有声音（包括通知音）都会被录下，但不会录下你的声音。

- **Windows**：运行 `mmsys.cpl`，在**录制**选项卡中右键单击列表以显示已禁用的设备，然后启用**立体声混音**。如果你的声卡没有这一项，请安装 [VB-CABLE](https://vb-audio.com/Cable/)，将 **CABLE Input** 设为输出设备，并在 Audiotext 中选择 **CABLE Output**。若要继续听到声音，请在 **CABLE Output** 的属性中勾选**侦听此设备**。
- **macOS**：安装 [BlackHole](https://existential.audio/blackhole/)（`brew install blackhole-2ch`），并在 Audiotext 中选择 **BlackHole 2ch**。若要继续听到声音，请用扬声器和 BlackHole 创建一个[多输出设备](https://github.com/ExistentialAudio/BlackHole/wiki/Multi-Output-Device)，并将其设为输出设备。
- **Linux**（PulseAudio 或 PipeWire）：在 Audiotext 中选择 **pulse** 并开始录音。然后在 `pavucontrol` 的**录音**选项卡中，将 Audiotext 的来源改为扬声器的监视器。

## 文件夹

转写文件夹中的所有音频和视频文件；如果在**文件夹**卡片中打开了**包含子文件夹**，也会转写其子文件夹中的文件。点击**选择文件夹…**或把文件夹拖到窗口中。Audiotext 会告诉你找到了多少个文件。要排除某些文件，请在**跳过匹配以下内容的文件**中输入它们的名称或路径，用逗号分隔（例如 `*.wav, drafts/*`）。隐藏文件总是会被跳过。

每个文件的转写会保存在该文件旁边（或保存到你在**输出**卡片中选择的其他文件夹），文件名相同，扩展名为所选的每种**文件类型**。例如选择 `.txt` 和 `.vtt` 时：

```text
files-to-transcribe
├── paranoid-android.mp3
├── paranoid-android.txt
├── paranoid-android.vtt
└── movies
    ├── mulholland-dr.avi
    ├── mulholland-dr.txt
    └── mulholland-dr.vtt
```

如果两个文件名称相同但扩展名不同（例如 `talk.mp3` 和 `talk.mp4`），它们的转写会在名称中保留扩展名（`talk.mp3.txt` 和 `talk.mp4.txt`），以免互相替换。

已有转写的文件会被**跳过**：只有当文件已有你选择的所有文件类型时才会跳过，因此添加一种文件类型会重新转写它。某个文件无法转写时，其余文件仍会继续转写。

### 文件夹中的文件

历史记录中文件夹的页面会列出其中的文件，并显示每个文件的状态、时长、大小和文本预览。你可以搜索文件、按状态筛选（**全部**、**已完成**、**失败** 或 **待处理**），并按名称、状态、时长或大小排序。被移动或删除的文件会标记为**找不到文件**。

- 点击文件可打开其转写；点击文件的 `⋯` 按钮（或右键点击文件）可复制其文本、直接打开其导出、摘要或翻译、在文件管理器中显示，或选择**重新转写此文件**。
- 用 `Ctrl`/`⌘` 或 `Shift` 选择多个文件，或用 `Ctrl+A` / `⌘A` 选择所有显示的文件，然后选择**重新转写**、**导出…**（将它们一起导出到一个 TXT、Markdown 或 Word 文件）或**从历史记录中移除…**。`Enter` 打开所选文件，`Esc` 清除选择。
- **重试失败项**会重新转写失败的文件。**重新扫描文件夹**只转写没有转写的文件（例如新文件），并告诉你有多少文件因已有转写而被跳过。
- 文件夹的 `⋯` 菜单中有**全部重新转写…**（重新转写其所有文件并替换其转写）、**全部导出…**（导出到一个文件）、从列表中移除缺失文件的选项，以及打开源文件夹或已保存文件所在文件夹的选项。
- 更改文件夹的设置后，会列出使用其他设置（引擎、模型、语言等）转写的文件，并提供**重新转写它们**按钮。

标题栏显示文件的保存位置，并链接到源文件夹。**编辑设置**可更改文件夹的设置，**保存并重新扫描**会用这些设置转写缺少转写的文件。

### 监视文件夹

在**文件夹**卡片中打开**监视文件夹**，即可持续转写添加到该文件夹（或其子文件夹）的文件，直到你点击**停止监视**。这适合录音笔或会议工具把录音复制到某个文件夹的场景。

- 文件夹中已有的文件会被跳过，除非你打开**转写文件夹中已有的文件**：这时会先转写没有转写的文件。
- 文件在完全复制后（大小不再变化时）才会被转写，因此大文件不会只转写一半。
- 关闭 Audiotext 时正在监视的文件夹，会在再次打开时继续监视，并从已经看到的文件之后继续。已停止的文件夹可以通过**继续监视**重新监视。
- 如果文件夹不可用（例如位于未连接的驱动器上），Audiotext 会等待它，而不是失败。
- 要转写其他内容或录音时，文件夹的监视会暂停（在此之前新的转写会显示**正在启动…**），之后再继续监视。
- 错误不会停止监视，一起转写的文件会在同一条通知中告知。

## 队列

在另一个转写进行时，你也可以设置新的转写：按钮会变为**添加到队列**，当前转写完成后开始。排队中和进行中的转写会显示在历史记录中。
