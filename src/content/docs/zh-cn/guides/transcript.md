在[历史记录](/zh-cn/guides/history/)中选择一个转写即可打开。工具栏可在**逐字稿**、**纯文本**和**摘要**三种模式之间切换，并提供**翻译**、**复制**和**导出**按钮。

## 逐字稿模式

显示转写的每个片段（一个句子，或长句的一部分）及其开始和结束时间；如果识别了说话人，还会显示说话人。

默认情况下，时间以简化形式显示（`01:05 – 01:09`）。要像字幕那样精确到毫秒显示（`00:01:05,900 – 00:01:09,350`），请在 `⋯` 菜单中勾选**精确时间戳 (00:00:01,000)**。

只有 **WhisperX** 以及 **Whisper API** 的 `whisper-1` 和 `gpt-4o-transcribe-diarize` 模型提供时间戳。没有时间戳时，逐字稿无法逐片段播放，请改用**纯文本**模式。

### 播放音频

- **点击片段**即可从该处播放音频。正在播放的片段会高亮，文本会跟随播放滚动。有逐词时间时，每个字词也会高亮。
- 使用播放栏可以播放、暂停、跳到任意位置，并在 `0.5×` 到 `2×` 之间调整**速度**，同时保持音调不变。
- 键盘快捷键：`Space` 播放或暂停，`←`/`→` 后退或前进 5 秒。

如果源文件被移动或删除，音频将不可用，但文本仍然保留。麦克风录音由 Audiotext 保存，因此随时可以播放。

### 带字幕观看视频

视频的转写会在文本上方显示视频。通过视频的菜单可以**在视频上显示字幕**，并选择字幕的**大小**（小、中、大）、**位置**（底部或顶部）和**样式**（深色背景或描边）。如果转写有[翻译](/zh-cn/guides/summary-and-translation/#翻译)，还可以在该菜单中选择字幕显示**转写**还是翻译。

### 搜索

按 `Ctrl+F`（macOS 上为 `⌘F`）并输入。`Enter` 和 `Shift+Enter` 跳到下一个和上一个匹配项，`Esc` 清除搜索。

## 校对转写

要在保留时间戳（字幕和播放会用到）的同时校对转写，请使用 `⋯` 菜单中的选项，或右键点击片段：

- **查找和替换…**：在整个转写中替换某个词或短语，例如拼错的人名。替换前会显示文本出现的次数，并可**区分大小写**。
- **重命名说话人…**：为每位说话人命名（`SPEAKER_00` → `小明`）。给两位说话人取相同的名字会将他们合并。
- **编辑文本…**：右键点击片段以修改其文本。
- **从此处播放**：右键点击片段以播放它。

未改动的字词会保留其时间，因此播放时仍会高亮。

## 纯文本

**纯文本**模式允许你像在文本编辑器中一样自由编辑文本。更改会自动保存。逐字稿保留带时间戳的原始文本，因此字幕不会使用纯文本中的编辑。

## 复制与导出

**复制**会复制当前模式的文本（逐字稿、摘要或翻译）。

**导出**（或 `Ctrl+S`，macOS 上为 `⌘S`）可将转写保存为：

| 格式 | 内容 |
| --- | --- |
| 纯文本 (`.txt`) | 文本 |
| Markdown (`.md`) | 摘要（如有），以及按段落排列、带每段时间戳和说话人的文本 |
| Word 文档 (`.docx`) | 与 Markdown 相同，可直接编辑或打印 |
| 字幕 (`.srt`) | 用于视频播放器的字幕 |
| 网页字幕 (`.vtt`) | 用于网页的字幕 |
| 表格 (`.tsv`) | 每个片段一行，包含开始和结束时间（毫秒）及文本 |
| JSON (`.json`) | 文本、带时间戳、字词和说话人的片段，以及摘要（如有） |

字幕和表格需要时间戳。

如果转写有翻译，在同一菜单中选择翻译（**…翻译**），或点击翻译的导出按钮，即可以相同格式导出翻译。文件名包含其语言（例如 `video.es.srt`），因此视频播放器会随视频一起加载它。

## 重命名、标签和备注

转写的标题栏会显示名称、来源、日期和标签。双击名称可重命名，点击标签可修改，点击**添加备注**可写备注。点击备注或其铅笔图标可编辑，点击其垃圾桶图标可删除。更多选项请见[历史记录](/zh-cn/guides/history/)。
