## 音频和视频格式

Audiotext 使用 FFmpeg 从视频文件中提取音频，因此两者都能转写。

**音频**：`.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**视频**：`.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## 输出格式

| 格式 | 导出 | 文件夹（WhisperX） | 文件夹（Whisper API） |
| --- | :---: | :---: | :---: |
| 纯文本 (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Word 文档 (`.docx`) | ✓ | ✗ | ✗ |
| 字幕 (`.srt`) | ✓ | ✓ | `srt` |
| 网页字幕 (`.vtt`) | ✓ | ✓ | `vtt` |
| 表格 (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Audacity 标签 (`.aud`) | ✗ | ✓ | ✗ |

请参阅[导出](/zh-cn/guides/transcript/#复制与导出)和[输出卡片](/zh-cn/guides/transcription-settings/#文件夹与输出)。
