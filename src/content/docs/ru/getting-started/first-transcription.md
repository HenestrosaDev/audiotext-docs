## Окно

Окно Audiotext состоит из трёх частей:

- **Верхняя панель**: кнопки для **Новой транскрипции** из **Файла**, по **URL**, с **Микрофона** или из **Папки**, состояние приложения и шестерёнка, открывающая [Предпочтения](/ru/reference/preferences/). Кнопка слева показывает или скрывает историю.
- **История** слева: все ваши транскрипции, которые можно искать, закреплять, группировать и переименовывать. См. [История](/ru/guides/history/).
- **Основная область**: источник, который вы настраиваете, ход транскрипции или транскрипция, выбранная в истории.

![Части окна Audiotext: верхняя панель, история и основная область](/screenshots/window.png)

При открытии приложения основная область спрашивает **Что вы хотите транскрибировать?** и показывает карточку для каждого типа источника.

:::tip
Перетащите файл или папку в любое место окна, чтобы транскрибировать его.
:::

## Транскрибируйте файл

1. Нажмите **Файл** на верхней панели (или `Ctrl+O`, `⌘O` в macOS) и выберите аудио- или видеофайл либо перетащите его в окно. Затем нажмите **Продолжить**.
2. Проверьте настройки. Значения по умолчанию подходят для большинства записей:
   - **Движок**: WhisperX, который работает на вашем компьютере. Если компьютер медленный, выберите модель поменьше (например, `small`) в поле **Модель**.
   - **Язык**: **Язык аудио** определяется автоматически. Если вы его знаете, выберите его, чтобы избежать ошибок. Для перевода выберите другой **Язык транскрипции**.
   - **Контекст** и **Параметры**: необязательные подсказки и функции, например определение говорящих.

   Все настройки описаны в разделе [Настройки транскрипции](/ru/guides/transcription-settings/).
3. Нажмите **Начать транскрипцию** (или `Ctrl+Enter`, `⌘↩` в macOS).

Во время работы показывается ход каждого шага (загрузка модели, транскрипция, выравнивание слов…). Тем временем можно продолжать пользоваться Audiotext: результат сохранится в истории и откроется, когда будет готов. Чтобы отменить транскрипцию, нажмите **Отмена** или `Esc`.

Если уже выполняется другая транскрипция, кнопка меняется на **Добавить в очередь**, и новая начнётся после завершения текущей.

## Читайте и используйте результат

По завершении транскрипция открывается:

- Нажмите на сегмент, чтобы воспроизвести аудио с этого места.
- Переключайтесь между режимами **Транскрипт**, **Простой текст** и **Сводка**.
- Кнопки **Перевести**, **Копировать** и **Экспорт** позволяют перевести, скопировать или сохранить её в файл.

Всё, что можно с ней сделать, описано в разделе [Транскрипт](/ru/guides/transcript/).

## Сочетания клавиш

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Enter` / `⌘↩` | Начать транскрипцию или начать и остановить запись |
| `Ctrl+O` / `⌘O` | Выбрать файл (или папку для источника «Папка») |
| `Ctrl+S` / `⌘S` | Экспортировать показанную транскрипцию |
| `Ctrl+F` / `⌘F` | Искать в транскрипции |
| `Esc` | Отменить выполняющуюся транскрипцию |
| `Пробел` | Воспроизвести или приостановить аудио |
| `←` / `→` | Назад или вперёд на 5 секунд |
