Audiotext — настольное приложение для **Windows**, **macOS** и **Linux**. Оно превращает в текст звук из файлов, видео с YouTube и записей с микрофона, а также умеет переводить его, составлять сводку и создавать субтитры.

## Скачайте приложение

Скачайте файл для своей системы из [последней версии](https://github.com/HenestrosaDev/audiotext/releases/latest) на GitHub:

| Система | Файл |
| --- | --- |
| Windows (64-разрядная) | `Audiotext-<version>-windows-x64-setup.exe` |
| macOS 15 или новее (Apple Silicon) | `Audiotext-<version>-macos-arm64.dmg` |
| Linux (x86_64) | `Audiotext-<version>-linux-x86_64.tar.gz` |

Приложение включает всё необходимое, в том числе FFmpeg.

### Windows

Запустите установщик и следуйте его шагам. Права администратора не нужны. Если у вас есть видеокарта NVIDIA, отметьте вариант использования видеокарты NVIDIA (CUDA): тогда установщик скачает GPU-дополнение, которое значительно ускоряет WhisperX. Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение: откройте подробные сведения и выберите запуск в любом случае.

### macOS

Откройте файл `.dmg` и перетащите **Audiotext** в папку **Программы**. Приложение не заверено Apple, поэтому macOS блокирует его при первом открытии: откройте **Системные настройки** → **Конфиденциальность и безопасность** и нажмите **Всё равно открыть** рядом с сообщением об Audiotext. В macOS WhisperX работает на процессоре, так как CUDA там недоступна. Компьютеры Mac с процессором Intel не поддерживаются, так как PyTorch больше их не поддерживает.

### Linux

Распакуйте архив и запустите установщик в терминале:

```bash
tar -xzf Audiotext-<version>-linux-x86_64.tar.gz
cd Audiotext-<version>-linux-x86_64
./install.sh
```

Он устанавливает Audiotext для вашего пользователя и добавляет его в меню приложений (его также можно открыть командой `audiotext`). Если он обнаружит видеокарту NVIDIA, то предложит скачать GPU-дополнение. Запустите `./install.sh --gpu` или `./install.sh --cpu`, чтобы выбрать без вопросов, и `./install.sh --uninstall`, чтобы удалить приложение (настройки сохраняются).

:::tip
GPU-дополнение весит около 2 ГБ в Windows и 4 ГБ в Linux, поэтому оно имеет смысл только с видеокартой NVIDIA. Без него WhisperX работает на процессоре, а Whisper API и Google API работают так же. Чтобы позже переключиться между версией для процессора и версией для GPU, установите приложение заново и выберите другой вариант.
:::

:::note
При первой транскрипции с помощью **WhisperX** (движка по умолчанию) скачивается его модель. Её размер — от ~75 МБ для `tiny` до ~3 ГБ для `large-v2`, поэтому это может занять некоторое время. Следующие транскрипции начинаются сразу.
:::

## Требования

- **WhisperX** работает на вашем компьютере. Он работает на любом процессоре, но гораздо быстрее на видеокарте NVIDIA с CUDA. В разделе [Движки](/ru/reference/engines/) можно подобрать модель под ваше оборудование.
- **Whisper API** и **Google API** работают на удалённых серверах, поэтому им нужно подключение к интернету, но не мощное оборудование.
- Для транскрипции с микрофона система должна распознавать устройство ввода.
- В Linux для записи и воспроизведения нужен [PortAudio](https://www.portaudio.com/) (`sudo apt install libportaudio2` в Ubuntu или Debian).

## Обновите приложение

Когда выходит новая версия, Audiotext показывает на верхней панели кнопку **Доступна версия …**. Нажмите её, чтобы открыть страницу выпуска, скачайте файл для своей системы и установите его так же, как в первый раз: в Windows запустите новый установщик, в macOS перетащите новое приложение в папку **Программы**, а в Linux запустите `install.sh` из нового архива. Предыдущая версия заменяется, а ваши настройки и история сохраняются, так как они хранятся в [папке пользовательской конфигурации](/ru/reference/files-and-data/#папка-пользовательской-конфигурации). Если вы используете дополнение для GPU, выберите его снова при установке.

Чтобы самостоятельно проверить наличие новой версии, откройте **Предпочтения** → **О программе** → **Проверить обновления**. Чтобы не проверять при запуске приложения, выключите **Общие** → **Обновления**.

## Смените язык интерфейса

Audiotext использует язык системы, если он доступен. Чтобы сменить его, откройте **Предпочтения** (шестерёнка в правом верхнем углу) и выберите язык в **Общие** → **Язык интерфейса**.
