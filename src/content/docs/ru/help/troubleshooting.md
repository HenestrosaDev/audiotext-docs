## Первая транскрипция с WhisperX занимает много времени

При первом использовании модель скачивается, что может занять несколько минут в зависимости от подключения и размера модели (до ~3 ГБ). Ход выполнения показывает, когда она загружается. Модель остаётся в памяти, пока не меняются её параметры, поэтому следующие транскрипции начинаются сразу.

## WhisperX завершается ошибкой `CUDA out of memory`

Видеокарте не хватает памяти для этих настроек. Попробуйте по порядку:

1. Уменьшите **Размер пакета** (например, до `4`) в **Предпочтения** → **WhisperX**.
2. Используйте модель поменьше (например, `small` или `base`).
3. Используйте более лёгкий **Тип вычислений** (например, `int8`).

Последние два варианта могут снизить качество. Сколько памяти нужно каждой модели, указано в разделе [Движки](/ru/reference/engines/#модель).

## Транскрипция занимает слишком много времени

Скорость WhisperX зависит от оборудования, поэтому на слабых процессорах не стоит ждать мгновенных результатов. Попробуйте модель поменьше, например `small`, `large-v3-turbo` на видеокарте или тип вычислений `int8`. Также можно использовать **Whisper API** или **Google API**, которые работают на удалённых серверах.

## Whisper API возвращает ошибку `429`

```text
RateLimitError("Error code: 429 - {'error': {'message': 'You exceeded your current quota, ...', 'type': 'insufficient_quota', ...}}")
```

На вашем счёте OpenAI закончились средства, или перед первым использованием API его нужно пополнить (даже если у вас есть бесплатные кредиты). Купите кредиты в разделе [Billing](https://platform.openai.com/settings/organization/billing/overview) учётной записи OpenAI. Активация может занять до 10 минут.

Если вы создали ключ API до первого пополнения и ошибка не исчезает через 10 минут, создайте новый ключ и задайте его в **Предпочтения** → **Ключи API**.

## Говорящие не определяются

Для определения говорящих нужен токен Hugging Face и принятие условий модели. Проверьте, что:

- Вы приняли условия [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) с той же учётной записью.
- У токена роль `Read` и он задан в **Предпочтения** → **Ключи API**.

См. [Определение говорящих](/ru/guides/transcription-settings/#определение-говорящих).

## Микрофон не найден или ничего не записывается

- Проверьте, что микрофон подключён, и нажмите кнопку обновления рядом со списком микрофонов.
- В macOS разрешите доступ для Audiotext в **Системные настройки** → **Конфиденциальность и безопасность** → **Микрофон**, в Windows — в **Параметры** → **Конфиденциальность** → **Микрофон**.
- Если индикатор уровня показывает **Нет звука**, выберите другой микрофон в списке или проверьте, не выключен ли звук.

## Аудио транскрипции не воспроизводится

Исходный файл перемещён или удалён. Текст сохраняется, но аудио можно воспроизвести только из исходного файла. Записи с микрофона и аудио по URL Audiotext хранит сам.

## Видео с YouTube не скачивается

Проверьте, что URL правильный, а видео общедоступно. YouTube часто меняется, поэтому, если ошибка повторяется, проверьте, нет ли более новой версии Audiotext.

## Папка не транскрибирует ни одного файла

Файлы, у которых уже есть транскрипция, пропускаются. Включите **Перезаписывать существующие файлы**, чтобы транскрибировать их снова. Папка также должна содержать [поддерживаемые файлы](/ru/reference/formats-and-languages/).

## Google API запрашивает язык

Google API не умеет определять язык. Выберите **Язык аудио** в настройках.
