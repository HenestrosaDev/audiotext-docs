**Предпочтения** содержат настройки, которые не меняются с каждой транскрипцией. Откройте их шестерёнкой в правом верхнем углу окна. Изменения сохраняются автоматически.

## Общие

- **Оформление**: **Системная** (как в системе), **Светлая** или **Тёмная**.
- **Размер интерфейса**: размер текста и элементов управления, от 80 % до 200 %. По умолчанию `100%`. Изменение применяется сразу.
- **Язык интерфейса**: язык Audiotext или **Язык системы**. См. [доступные языки](/ru/reference/formats-and-languages/#языки-интерфейса).
- **Формат даты**: как показываются даты транскрипций на языке интерфейса: короткий (`04.10.2026`), средний (`4 окт. 2026 г.`, по умолчанию), длинный (`4 октября 2026 г.`) или ISO (`2026-10-04`). Меню показывает каждый формат на примере.
- **Формат времени**: **Автоматически** (часы языка интерфейса), 12-часовой (`1:30 PM`) или 24-часовой (`13:30`).
- **Уведомления**: показывает системное уведомление, когда транскрипция готова (для папки — когда готовы все её файлы, а для отслеживаемой папки — каждый раз, когда готовы новые файлы, одним уведомлением). Включено по умолчанию. В macOS они приходят от **Редактора скриптов**, а в Windows — от **Windows PowerShell**, поэтому их разрешают или отключают для этих приложений в настройках системы. В Linux для них нужен `notify-send` (пакет `libnotify-bin` или `libnotify`).
- **Проверять обновления автоматически**: при запуске приложения проверяет наличие новой версии и, если она есть, показывает на верхней панели кнопку **Доступна версия …**, которая открывает страницу загрузки. Предварительные версии не предлагаются. Включено по умолчанию.

## Поставщики

Поставщики [сводок, вопросов и переводов](/ru/guides/summary-and-translation/):

- **Сводка** → **Поставщик** и **Модель**.
- **Спросить** → **Поставщик** и **Модель**: те, что отвечают на вопросы о транскрипциях. Пока вы их не измените, это поставщик и модель сводок.
- **Перевод** → **Поставщик** и **Модель**. У DeepL и Google Translate нет моделей на выбор.
- **Ollama** → **URL сервера**: адрес Ollama, по умолчанию `http://localhost:11434`.

Оставьте поле **Модель** пустым, чтобы использовать модель поставщика по умолчанию. Кнопка рядом с поставщиком задаёт его ключ API.

## Ключи API

Ключи каждой службы. Нажмите **Задать ключ API…**, чтобы ввести ключ, или **Изменить ключ API…**, чтобы заменить его (оставьте поле пустым, чтобы удалить ключ). Они хранятся в хранилище учётных данных системы. Они сгруппированы по назначению, а заданные ключи отмечены галочкой.

| Группа | Ключ | Для чего нужен |
| --- | --- | --- |
| **Поставщики LLM** | Ключ API OpenAI | Whisper API, а также сводки, вопросы и переводы с OpenAI |
| | Ключ API Anthropic | Сводки, вопросы и переводы с Claude |
| | Ключ API DeepSeek | Сводки, вопросы и переводы с DeepSeek |
| | Ключ API Gemini | Сводки, вопросы и переводы с Gemini (из Google AI Studio) |
| | Ключ API Mistral | Сводки, вопросы и переводы с Mistral |
| | Ключ API xAI | Сводки, вопросы и переводы с Grok |
| **Перевод** | Ключ API DeepL | Переводы с DeepL (ключи бесплатного тарифа тоже подходят) |
| | Ключ Google API | Google Speech-to-Text сверх бесплатного лимита и Google Translate (Cloud Translation API) |
| **Транскрипция** | Токен Hugging Face | Определение говорящих в WhisperX |

:::caution
Каждый поставщик берёт плату за использование своего API, за что Audiotext не отвечает. Если OpenAI возвращает ошибку `429` с новым ключом, см. [Устранение неполадок](/ru/help/troubleshooting/#whisper-api-возвращает-ошибку-429).
:::

## Транскрипция

Параметры движков, каждый в своём разделе.

### WhisperX

**Тип вычислений**, **Размер пакета** и **Использовать CPU**. См. [расширенные параметры WhisperX](/ru/reference/engines/#расширенные-параметры). На Mac с Apple Silicon WhisperX транскрибирует на его графическом процессоре, если не включено **Использовать CPU**. См. [На Mac](/ru/reference/engines/#на-mac). На графическом процессоре Mac подсказки **Тип вычислений** и **Размер пакета** сообщают, что они не применяются, а у **Использовать CPU** есть ссылка на **Поддерживаемые модели**.

### Whisper API

**Температура** и **Временные метки слов**. См. [параметры Whisper API](/ru/reference/engines/#параметры).

## Субтитры

Как делятся субтитры: показанные на видео и в режиме **Субтитры**, экспортируемые файлы субтитров и [видео с субтитрами](/ru/guides/transcript/#экспорт-видео-с-субтитрами). У каждого параметра есть значение для горизонтальных видео и для вертикальных (выше, чем шире, например для телефонов), которые уже:

| Параметр | Горизонтальные | Вертикальные |
| --- | :---: | :---: |
| **Макс. строк в субтитре** | `2` | `2` |
| **Макс. символов в строке** | `42` | `24` |
| **Китайский, японский и корейский**: символов в строке на этих языках, символы которых примерно вдвое шире латинских | `16` | `10` |

Строки субтитра выравниваются по длине, а языки без пробелов переносятся между символами.

**Выделять слова** подчёркивает в файлах `.srt` и `.vtt` каждое слово в момент его произнесения. По умолчанию выключено.
