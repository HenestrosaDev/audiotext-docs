**Предпочтения** содержат настройки, которые не меняются с каждой транскрипцией. Откройте их шестерёнкой в правом верхнем углу окна. Изменения сохраняются автоматически.

## Общие

- **Оформление**: **Системная** (как в системе), **Светлая** или **Тёмная**.
- **Язык интерфейса**: язык Audiotext или **Язык системы**. См. [доступные языки](/ru/reference/formats-and-languages/#языки-интерфейса).
- **Формат даты**: как показываются даты транскрипций на языке интерфейса: короткий (`04.10.2026`), средний (`4 окт. 2026 г.`, по умолчанию), длинный (`4 октября 2026 г.`) или ISO (`2026-10-04`). Меню показывает каждый формат на примере.
- **Формат времени**: **Автоматически** (часы языка интерфейса), 12-часовой (`1:30 PM`) или 24-часовой (`13:30`).
- **Уведомления**: показывает системное уведомление, когда транскрипция готова (для папки — когда готовы все её файлы, а для отслеживаемой папки — каждый раз, когда готов новый файл). Включено по умолчанию. В macOS они приходят от **Редактора скриптов**, а в Windows — от **Windows PowerShell**, поэтому их разрешают или отключают для этих приложений в настройках системы. В Linux для них нужен `notify-send` (пакет `libnotify-bin` или `libnotify`).

## ИИ

Поставщики [сводок и переводов](/ru/guides/summary-and-translation/):

- **Сводка** → **Поставщик** и **Модель**.
- **Перевод** → **Поставщик** и **Модель**. У DeepL и Google Translate нет моделей на выбор.
- **Ollama** → **URL сервера**: адрес Ollama, по умолчанию `http://localhost:11434`.

Оставьте поле **Модель** пустым, чтобы использовать модель поставщика по умолчанию. Кнопка рядом с поставщиком задаёт его ключ API.

## Ключи API

Ключи каждой службы. Нажмите **Задать…**, чтобы ввести ключ, или **Изменить…**, чтобы заменить его (оставьте поле пустым, чтобы удалить ключ). Они хранятся в хранилище учётных данных системы.

| Ключ | Для чего нужен |
| --- | --- |
| Ключ API OpenAI | Whisper API, а также сводки и переводы с OpenAI |
| Ключ API Anthropic | Сводки и переводы с Claude |
| Ключ API DeepSeek | Сводки и переводы с DeepSeek |
| Ключ API Gemini | Сводки и переводы с Gemini (из Google AI Studio) |
| Ключ API Mistral | Сводки и переводы с Mistral |
| Ключ API xAI | Сводки и переводы с Grok |
| Ключ API DeepL | Переводы с DeepL (ключи бесплатного тарифа тоже подходят) |
| Ключ Google API | Google Speech-to-Text сверх бесплатного лимита и Google Translate (Cloud Translation API) |
| Токен Hugging Face | Определение говорящих в WhisperX |

:::caution
Каждый поставщик берёт плату за использование своего API, за что Audiotext не отвечает. Если OpenAI возвращает ошибку `429` с новым ключом, см. [Устранение неполадок](/ru/help/troubleshooting/#whisper-api-возвращает-ошибку-429).
:::

## Субтитры

Параметры файлов `.srt` и `.vtt`, которые сохраняются при транскрипции папки с помощью WhisperX:

- **Выделять слова**: подчёркивает каждое слово в момент его произнесения. По умолчанию выключено.
- **Макс. число строк**: максимальное число строк в каждом субтитре. По умолчанию `2`.
- **Макс. ширина строки**: максимальное число символов в строке до переноса. По умолчанию `42`.
