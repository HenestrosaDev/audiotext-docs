## Аудио- и видеоформаты

Audiotext извлекает звук из видеофайлов с помощью FFmpeg, поэтому транскрибирует и то и другое.

**Аудио**: `.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**Видео**: `.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## Выходные форматы

| Формат | Экспорт | Папка (WhisperX) | Папка (Whisper API) |
| --- | :---: | :---: | :---: |
| Простой текст (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Документ Word (`.docx`) | ✓ | ✗ | ✗ |
| Субтитры (`.srt`) | ✓ | ✓ | `srt` |
| Веб-субтитры (`.vtt`) | ✓ | ✓ | `vtt` |
| Таблица (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Метки Audacity (`.aud`) | ✗ | ✓ | ✗ |

См. [Экспорт](/ru/guides/transcript/#копирование-и-экспорт) и [карточку «Вывод»](/ru/guides/transcription-settings/#папка-и-вывод).
