Audiotext хранит ваши данные на вашем компьютере. Ничего никуда не отправляется, если только вы не используете удалённый движок (Whisper API или Google API) или поставщика ИИ, отличного от Ollama. При запуске оно также спрашивает GitHub, есть ли новая версия; это можно отключить в **Предпочтения** → **Общие** → **Обновления**.

## Папка пользовательской конфигурации

Настройки, история и записи хранятся в папке пользовательской конфигурации, поэтому сохраняются при обновлениях:

| Система | Папка |
| --- | --- |
| Windows | `%APPDATA%\Audiotext` |
| macOS | `~/Library/Application Support/Audiotext` |
| Linux | `~/.config/audiotext` (или `$XDG_CONFIG_HOME/audiotext`) |

В ней находятся:

- `config.ini`: ваши настройки. Удалите его, чтобы вернуть значения по умолчанию.
- `history.json`: ваши транскрипции со сводками, переводами и исправлениями.
- `media/`: записи с микрофона и аудио, скачанное по URL, чтобы их можно было воспроизвести позже. Они удаляются вместе с соответствующей транскрипцией из истории.

Чтобы использовать другую папку, например для портативной установки, задайте переменную окружения `AUDIOTEXT_CONFIG_DIR`.

:::note
Файл `config.ini` в папке приложения содержит настройки по умолчанию и никогда не изменяется.
:::

## Ключи API

Ключи API и токен Hugging Face хранятся в хранилище учётных данных системы:

- **macOS**: Связка ключей.
- **Windows**: Диспетчер учётных данных.
- **Linux**: Secret Service (например, GNOME Keyring или KWallet).

Если в системе его нет (например, на сервере без рабочего стола), они хранятся в файле `.env` в папке конфигурации, доступном для чтения только вашему пользователю. Ключи, которые предыдущие версии хранили в этом файле, переносятся в хранилище учётных данных при первом запуске приложения.

Ключи используются **только** для запросов к API соответствующей службы.

## Переменные окружения

Переменные окружения с именами ключей имеют приоритет над ключами, заданными в приложении:

| Переменная | Служба |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI (Whisper API, сводки, переводы) |
| `ANTHROPIC_API_KEY` | Claude |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `GEMINI_API_KEY` | Gemini |
| `MISTRAL_API_KEY` | Mistral |
| `XAI_API_KEY` | Grok (xAI) |
| `DEEPL_API_KEY` | DeepL |
| `GOOGLE_API_KEY` | Google Speech-to-Text и Google Translate |
| `HF_TOKEN` | Hugging Face (определение говорящих) |
| `AUDIOTEXT_CONFIG_DIR` | Папка настроек и истории |

## Модели

Модели WhisperX и определения говорящих скачиваются при первом использовании и кешируются Hugging Face в `~/.cache/huggingface` (`%USERPROFILE%\.cache\huggingface` в Windows). Модели, которые выравнивают слова английского, французского, немецкого, испанского и итальянского языков, кеширует PyTorch в `~/.cache/torch` (`%USERPROFILE%\.cache\torch` в Windows). Удалите эти папки, чтобы освободить занимаемое ими место. Другие приложения тоже могут хранить там свои модели и, как Audiotext, скачивают их заново, когда они нужны.
