Audiotext можно использовать и из командной строки, например чтобы транскрибировать из скриптов. Есть три команды:

- `transcribe`: транскрибирует файл, файлы папки или видео с YouTube.
- `watch`: транскрибирует файлы, добавляемые в папку, пока не будет остановлена через `Ctrl+C`.
- `check-update`: проверяет, доступна ли новая версия, и выводит ссылку для её загрузки.

Не указанные параметры берут значения из настроек приложения. Транскрипции всегда сохраняются рядом с каждым транскрибированным файлом или в папке, указанной через `--output-dir` (в ней воссоздаются подпапки транскрибированной папки).

## Запуск

Установленное приложение запускает командную строку, когда получает одну из её команд:

| Система | Команда |
| --- | --- |
| Linux | `audiotext` (устанавливается в `~/.local/bin` скриптом `install.sh`) |
| macOS | `/Applications/Audiotext.app/Contents/MacOS/Audiotext` |
| Windows | `audiotext-cli.exe` в папке, куда установлен Audiotext (по умолчанию `%LOCALAPPDATA%\Programs\Audiotext`) |

Если вы [запускаете его из исходного кода](/ru/help/contributing/#подготовка-проекта), используйте вместо этого `uv run src/cli.py`.

## Примеры

```bash
# Транскрибировать файл. Текст также выводится, поэтому его можно перенаправить
audiotext transcribe interview.mp3 --language es --output-types txt,srt

# Транскрибировать файлы папки с определением говорящих
audiotext transcribe recordings/ --diarize --speakers 2 --output-dir transcriptions/

# Транскрибировать видео с YouTube с помощью Whisper API
audiotext transcribe "https://www.youtube.com/watch?v=…" --method whisper-api

# Транскрибировать встречу с помощью Whisper API, с ключевыми словами и контекстом
audiotext transcribe meeting.m4a --method whisper-api \
    --openai-model gpt-transcribe --keywords "Audiotext, WhisperX" \
    --prompt "Встреча о следующей версии"

# Сохранить субтитры и документ Word, составить сводку и перевести на испанский
audiotext transcribe talk.mp4 --output-types srt,docx --summarize --translate-to es

# Транскрибировать файлы, добавляемые в папку, до остановки через Ctrl+C
audiotext watch inbox/ --output-types srt
```

## Параметры

| Параметр | Описание |
| --- | --- |
| `-m`, `--method` | Метод транскрипции: `whisperx`, `whisper-api` или `google` |
| `-l`, `--language` | Язык аудио в виде кода ISO 639-1 (например, `ru`) или `auto` для определения (не поддерживается Google) |
| `-t`, `--output-types` | Типы выходных файлов через запятую из `aud`, `json`, `srt`, `txt`, `tsv`, `vtt`, `md`, `docx` и `ass` (например, `txt,srt,md`) |
| `-o`, `--output-dir` | Папка для сохранения транскрипций (по умолчанию — рядом с каждым транскрибированным файлом) |
| `--overwrite` | Перезаписывать существующие транскрипции |
| `-p`, `--prompt` | О чём запись, например тема или обстановка (не поддерживается Google) |
| `-k`, `--keywords` | Имена, термины или аббревиатуры из записи через запятую, чтобы они писались правильно (не поддерживается Google) |
| `--translate` | Переводить аудио на английский при транскрипции (не поддерживается Google). Для других языков см. `--translate-to` |
| `-q`, `--quiet` | Выводить только ошибки |
| `-v`, `--verbose` | Выводить журналы для отладки ошибок |
| `--version` | Вывести версию Audiotext |

Типы вывода, которые метод транскрипции не сохраняет сам (например, `md` или `docx`), экспортируются из его результата, как в приложении. `aud` сохраняет только WhisperX.

**Параметры сводки и перевода**

| Параметр | Описание |
| --- | --- |
| `--summarize` | Составить сводку каждой транскрипции с ключевыми моментами и главами в файле `.summary.md` |
| `--summary-provider` | Поставщик языковой модели, которая составляет сводку: `openai`, `anthropic`, `deepseek`, `gemini`, `mistral`, `grok` или `ollama` |
| `--summary-model` | Языковая модель, которая составляет сводку |
| `--translate-to` | Перевести каждую транскрипцию на язык (код ISO 639-1); перевод сохраняется в её типах выходных файлов (например, `talk.es.srt`) |
| `--translation-provider` | Поставщик переводов: те же, что для `--summary-provider`, а также `deepl` или `google` |
| `--translation-model` | Языковая модель для перевода, для поставщиков языковых моделей |

Если они не указаны, используются поставщики и модели из настроек приложения. См. [Поставщики](/ru/guides/summary-and-translation/#поставщики).

**Параметры WhisperX**

| Параметр | Описание |
| --- | --- |
| `--diarize` | Определять говорящих |
| `--speakers` | Количество говорящих при определении (`0` — определить автоматически) |
| `--model-size` | Модель, например `small` или `large-v2` (см. [Движки](/ru/reference/engines/#модель)) |
| `--compute-type` | `int8`, `float16` или `float32` |
| `--batch-size` | Размер пакета |
| `--cpu` | Запускать на процессоре, а не на видеокарте NVIDIA или графическом процессоре Mac |

**Параметры Whisper API**

| Параметр | Описание |
| --- | --- |
| `--openai-model` | Модель транскрипции: `whisper-1`, `gpt-transcribe` или `gpt-4o-transcribe-diarize` |

Выполните `audiotext transcribe --help`, чтобы увидеть все параметры и их значения.

## Вывод и код завершения

Ход выполнения выводится в стандартный поток ошибок (скройте его с помощью `--quiet`), а текст транскрипции одного файла — в стандартный вывод. Команда завершается с кодом `1`, если не удалась транскрипция, сводка или перевод, и с кодом `130`, если она остановлена через `Ctrl+C`.

Если ключ API поставщика для `--summarize` или `--translate-to` не задан, команда останавливается до транскрипции. Неудачная сводка или перевод сообщается без потери транскрипции, которая всё равно сохраняется.

Ключи API берутся из приложения или из их [переменных окружения](/ru/reference/files-and-data/#переменные-окружения), например `OPENAI_API_KEY`, `GOOGLE_API_KEY` и `HF_TOKEN` (для определения говорящих).
