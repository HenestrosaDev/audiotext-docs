Перед транскрипцией Audiotext показывает её настройки, сгруппированные в карточки. Они запоминаются на следующий раз, а каждая транскрипция сохраняет настройки, с которыми она была сделана.

![Настройки транскрипции файла](/screenshots/transcription-settings.png)

## Движок

**Метод транскрипции**:

| Движок | Где работает | Стоимость | Примечания |
| --- | --- | --- | --- |
| **WhisperX** (по умолчанию) | Ваш компьютер | Бесплатно и без ограничений | Приватно и офлайн. Больше возможностей: говорящие, тайминг слов, живой текст. |
| **Whisper API** | Серверы OpenAI | Оплата за минуту | Нужен [ключ API OpenAI](/ru/reference/preferences/#ключи-api). Для компьютеров, на которых WhisperX работает медленно. |
| **Google API** | Серверы Google | Бесплатный лимит или платно | Ниже качество и нет временных меток. Ключ API необязателен. |

**Модель** зависит от движка. У WhisperX большие модели точнее, но медленнее. У Whisper API модель определяет, будут ли в транскрипции временные метки и говорящие. Сравнение — в разделе [Движки](/ru/reference/engines/).

## Язык

- **Язык аудио**: по умолчанию **Автоопределение**. Если выбрать его вручную, можно избежать ошибок в коротких или смешанных записях. Google API не умеет определять язык, поэтому для него язык нужно выбрать.
- **Язык транскрипции**: по умолчанию **Как у аудио**. Выберите другой язык, чтобы перевести аудио во время транскрипции.

Если языки различаются, появляются параметры раздела **Перевод**:

- **Переводить с помощью Whisper (рекомендуется)**: Whisper транскрибирует и переводит аудио за один шаг. Переводит только на английский.
- **Писать сразу на нужном языке (_язык_, экспериментально)**: Whisper просят сразу писать транскрипцию на этом языке. Для многих языков это работает хорошо, но проверяйте результат.

Google API не умеет переводить. Чтобы позже перевести транскрипцию на любой язык с помощью других поставщиков, используйте кнопку [Перевести](/ru/guides/summary-and-translation/#перевод) в транскрипте.

## Контекст

Два необязательных поля, которые помогают модели:

- **Ключевые слова**: имена, термины или аббревиатуры, звучащие в записи, через запятую (например, `Audiotext, WhisperX, Henestrosa`), чтобы они писались правильно. Это только подсказки: ключевое слово появится, только если оно звучит в записи.
- **Описание**: о чём запись, например её тема или обстановка (например, `Интервью о распознавании речи`).

Их используют WhisperX и Whisper API, кроме модели `gpt-4o-transcribe-diarize`. Google API их не использует.

## Параметры

- **Тайминг слов** (WhisperX): выравнивает каждое слово по аудио, чтобы подсвечивать его при воспроизведении. Занимает немного больше времени. Субтитры его уже используют.
- **Выделять речь**: перед транскрипцией приглушает музыку и фоновый шум.
- **Определять говорящих** (WhisperX): помечает, кто говорит в каждой части, например `SPEAKER_00`. Если вы знаете, сколько человек говорит, укажите это в поле **Количество говорящих** (`0` — определить автоматически). Нужен бесплатный токен Hugging Face; см. [Определение говорящих](#определение-говорящих). В Whisper API говорящих определяет модель `gpt-4o-transcribe-diarize`.

### Определение говорящих

Модель, определяющая говорящих, [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1), бесплатна, но для неё нужен токен Hugging Face:

1. Создайте учётную запись на [Hugging Face](https://huggingface.co/join) и примите условия [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1).
2. Создайте токен с ролью `Read` в [своих настройках](https://huggingface.co/settings/tokens).
3. Нажмите **Задать токен Hugging Face…** и вставьте его.

Модель скачивается при первом использовании. После этого говорящие определяются офлайн.

## Папка и Вывод

Показываются только для папок:

- **Отслеживать папку**: см. [Отслеживание папки](/ru/guides/sources/#отслеживание-папки).
- **Типы файлов**: для WhisperX — один или несколько из `.txt`, `.srt`, `.vtt`, `.json`, `.tsv` и `.aud`. Для Whisper API — формат файлов (`text`, `json`, `verbose_json`, `srt` или `vtt`); для субтитров нужна модель с временными метками. Google API возвращает простой текст (`.txt`).
- **Расположение**: файлы сохраняются рядом с каждым исходным файлом. Нажмите **Изменить…**, чтобы сохранять их в другую папку (её подпапки будут воссозданы), или **Рядом с источником**, чтобы вернуться.
- **Перезаписывать существующие файлы**: заново транскрибирует файлы, у которых уже есть транскрипция, и заменяет её.

Параметры субтитров (ширина строки, число строк, выделение слов) находятся в [Предпочтениях](/ru/reference/preferences/#субтитры).
