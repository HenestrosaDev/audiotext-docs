Когда транскрипция готова, Audiotext может составить её сводку и перевести её с помощью языковой модели или службы перевода. И то и другое сохраняется в истории, поэтому создаётся только один раз.

## Сводка

Откройте режим **Сводка** транскрипции и нажмите **Создать сводку**. Языковая модель напишет:

- **Сводку** транскрипции.
- Её **ключевые моменты**.
- Её **главы**, если есть временные метки. Нажмите на главу, чтобы воспроизвести аудио с её начала.

**Создать заново** пишет сводку повторно (например, после выбора другой модели). **Копировать** копирует её, а [экспорт](/ru/guides/transcript/#копирование-и-экспорт) в Markdown и Word включает её.

Если ключ API поставщика не задан, режим **Сводка** предложит его задать. Очень длинные транскрипции (примерно три часа речи и больше) обобщаются только с начала.

## Перевод

Нажмите **Перевести**, выберите язык в поле **Перевести на** и **Поставщика**, затем подтвердите. Перевод появится на панели справа от исходного текста.

- Если у транскрипции есть временные метки, каждая фраза переводится отдельно, и перевод их сохраняет: подсвечивает воспроизводимую фразу, а нажатие на фразу воспроизводит её.
- Если вы редактировали простой текст, переводится отредактированный текст, без временных меток.
- Перетащите разделитель между текстами, чтобы изменить их размер, или дважды щёлкните его, чтобы вернуть исходные размеры.
- Кнопка **Перевести** также позволяет **Скрыть перевод**, **Перевести на другой язык…** или **Удалить перевод**.

:::tip
Чтобы сразу получить транскрипцию на другом языке без поставщика, можно переводить и во время транскрипции. См. [Язык](/ru/guides/transcription-settings/#язык).
:::

## Поставщики

Поставщики выбираются в **Предпочтения** → **ИИ**, отдельно для сводок и для переводов.

| Поставщик | Модель по умолчанию | Ключ API |
| --- | --- | --- |
| OpenAI (по умолчанию) | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude (Anthropic) | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini (Google) | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama (локально) | `llama3.2` | Не нужен |

Оставьте поле **Модель** пустым, чтобы использовать модель поставщика по умолчанию, или введите название любой другой его модели (например, `claude-sonnet-5-5` или `deepseek-reasoner`).

Переводить также можно с помощью:

- **DeepL** — нужен [ключ API DeepL](https://www.deepl.com/your-account/keys). Ключи бесплатного тарифа тоже подходят.
- **Google Translate** — используется ключ Google API с включённым Cloud Translation API.

### Ollama

[Ollama](https://ollama.com) запускает модели на вашем компьютере, без ключа API и без отправки текста куда-либо. Установите её, скачайте модель (например, `ollama pull llama3.2`) и выберите **Ollama** в качестве поставщика. Если она работает не по адресу по умолчанию, измените **URL сервера** в **Предпочтения** → **ИИ** (по умолчанию `http://localhost:11434`).

:::note
Каждый поставщик берёт плату за использование своего API, за что Audiotext не отвечает. Ключи API хранятся в хранилище учётных данных системы. См. [Файлы и данные](/ru/reference/files-and-data/).
:::
