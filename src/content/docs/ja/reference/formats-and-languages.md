## 音声・動画形式

Audiotext は FFmpeg で動画ファイルから音声を取り出すので、どちらも文字起こしできます。

**音声**: `.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**動画**: `.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## 出力形式

| 形式 | エクスポート | フォルダー（WhisperX） | フォルダー（Whisper API） |
| --- | :---: | :---: | :---: |
| プレーンテキスト (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Word 文書 (`.docx`) | ✓ | ✗ | ✗ |
| 字幕 (`.srt`) | ✓ | ✓ | `srt` |
| Web 字幕 (`.vtt`) | ✓ | ✓ | `vtt` |
| 表 (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Audacity ラベル (`.aud`) | ✗ | ✓ | ✗ |

[エクスポート](/ja/guides/transcript/#コピーとエクスポート)と[出力カード](/ja/guides/transcription-settings/#フォルダーと出力)をご覧ください。

## インターフェースの言語

Audiotext のインターフェースとこのドキュメントは、次の言語で利用できます。

| 言語 | | 言語 | |
| --- | --- | --- | --- |
| Català | カタルーニャ語 | Polski | ポーランド語 |
| Čeština | チェコ語 | Português | ポルトガル語 |
| Deutsch | ドイツ語 | Română | ルーマニア語 |
| English | 英語 | Русский | ロシア語 |
| Español | スペイン語 | Svenska | スウェーデン語 |
| Français | フランス語 | Türkçe | トルコ語 |
| Galego | ガリシア語 | Українська | ウクライナ語 |
| हिन्दी | ヒンディー語 | Tiếng Việt | ベトナム語 |
| Bahasa Indonesia | インドネシア語 | 简体中文 | 中国語（簡体字） |
| Italiano | イタリア語 | 日本語 | 日本語 |
| Nederlands | オランダ語 | 한국어 | 韓国語 |

**環境設定** → **一般** → **インターフェースの言語** で変更します。翻訳の改善や言語の追加については[コントリビュート](/ja/help/contributing/#インターフェースを翻訳する)をご覧ください。
