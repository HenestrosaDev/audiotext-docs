**環境設定** には、文字起こしごとに変わらない設定があります。ウィンドウ右上の歯車から開きます。変更は自動で保存されます。

## 一般

- **外観**: **システム**（システムに従う）、**ライト**、**ダーク**。
- **インターフェースのサイズ**: テキストとコントロールのサイズ。80% から 200% まで。既定値は `100%`。変更はすぐに反映されます。
- **インターフェースの言語**: Audiotext の言語、または **システムの言語**。[利用できる言語](/ja/reference/formats-and-languages/#インターフェースの言語)をご覧ください。
- **日付の形式**: 文字起こしの日付を表示する形式で、インターフェースの言語に従います。短い形式（`2026/10/04`）、中間の形式（既定）、長い形式（`2026年10月4日`）、ISO（`2026-10-04`）から選べます。メニューには各形式が例とともに表示されます（同じ見た目になる形式は 1 つだけ表示されます）。
- **時刻の形式**: **自動**（インターフェースの言語の時計）、12 時間制（`午後1:30`）、24 時間制（`13:30`）。
- **通知**: 文字起こしが完了したときにシステムの通知を表示します（フォルダの場合は、すべてのファイルが完了したとき。監視中のフォルダの場合は、新しいファイルが完了するたび）。既定でオンです。macOS では **スクリプトエディタ**、Windows では **Windows PowerShell** からの通知として表示されるため、システムの設定でこれらのアプリの通知を許可または停止します。Linux では `notify-send`（`libnotify-bin` または `libnotify` パッケージ）が必要です。
- **アップデート**: アプリを開いたときに新しいバージョンを確認し、ある場合は上部バーに **バージョン … が利用可能です** ボタンを表示します。このボタンでダウンロードページが開きます。プレリリース版は案内されません。既定ではオンです。

## AI

[要約、質問、翻訳](/ja/guides/summary-and-translation/)のプロバイダーです。

- **要約** → **プロバイダー** と **モデル**。
- **質問** → **プロバイダー** と **モデル**: 文字起こしについての質問に答えるものです。変更するまでは要約のものと同じです。
- **翻訳** → **プロバイダー** と **モデル**。DeepL と Google Translate には選べるモデルはありません。
- **Ollama** → **サーバー URL**: Ollama のアドレス。既定は `http://localhost:11434`。

**モデル** を空にするとプロバイダーの既定のモデルを使います。プロバイダーの横のボタンで、その API キーを設定します。

## API キー

各サービスのキーです。**API キーを設定…** をクリックしてキーを入力するか、**API キーを変更…** で置き換えます（空にすると削除されます）。キーはシステムの資格情報ストアに保存されます。

| キー | 用途 |
| --- | --- |
| OpenAI の API キー | Whisper API、および OpenAI での要約・質問・翻訳 |
| Anthropic の API キー | Claude での要約・質問・翻訳 |
| DeepSeek の API キー | DeepSeek での要約・質問・翻訳 |
| Gemini の API キー | Gemini（Google AI Studio）での要約・質問・翻訳 |
| Mistral の API キー | Mistral での要約・質問・翻訳 |
| xAI の API キー | Grok での要約・質問・翻訳 |
| DeepL の API キー | DeepL での翻訳（無料プランのキーも使えます） |
| Google の API キー | 無料枠を超える Google Speech-to-Text と、Google Translate（Cloud Translation API） |
| Hugging Face のトークン | WhisperX での話者の識別 |

:::caution
各プロバイダーは API の利用料金を請求します。これについて Audiotext は責任を負いません。新しいキーで OpenAI がエラー `429` を返す場合は、[トラブルシューティング](/ja/help/troubleshooting/#whisper-api-がエラー-429-を返す)をご覧ください。
:::

## WhisperX

**計算タイプ**、**バッチサイズ**、**CPU を使用**。[WhisperX の詳細オプション](/ja/reference/engines/#詳細オプション)をご覧ください。Apple シリコン搭載の Mac では、**CPU を使用** がオンでない限り、WhisperX は GPU で文字起こしします。[Mac の場合](/ja/reference/engines/#mac-の場合)をご覧ください。

## 字幕

字幕の分け方です。動画の上や **字幕** モードに表示される字幕、エクスポートした字幕ファイル、[字幕付き動画](/ja/guides/transcript/#字幕付きの動画をエクスポートする)に適用されます。各オプションには、横長の動画用と、幅が狭い縦長の動画（スマートフォン向けなど、幅より高さがあるもの）用の値があります。

| オプション | 横長 | 縦長 |
| --- | :---: | :---: |
| **字幕 1 つの最大行数** | `2` | `2` |
| **1 行の最大文字数** | `42` | `24` |
| **中国語・日本語・韓国語**: これらの言語での 1 行の文字数（文字幅がラテン文字の約 2 倍のため） | `16` | `10` |

字幕の各行の長さはそろえられ、スペースなしで書く言語は文字の間で改行されます。

**単語をハイライト** は、`.srt` と `.vtt` ファイルで各単語を話されたタイミングで下線表示します。既定ではオフです。
