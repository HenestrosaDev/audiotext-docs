## ウィンドウ

Audiotext のウィンドウは 3 つの部分でできています。

- **上部のバー**: **ファイル**、**URL**、**マイク**、**フォルダー** から**新しい文字起こし**を始めるボタン、アプリの状態、[環境設定](/ja/reference/preferences/)を開く歯車があります。左のボタンで履歴を表示・非表示にできます。
- **履歴**（左側）: すべての文字起こしが並び、検索、固定、グループ化、名前の変更ができます。[履歴](/ja/guides/history/)をご覧ください。
- **メイン領域**: 設定中のソース、文字起こしの進捗、または履歴で選んだ文字起こしが表示されます。

![Audiotext のウィンドウの各部:上部バー、履歴、メイン領域](/screenshots/window.png)

アプリを開くと、メイン領域に **何を文字起こししますか？** と表示され、ソースの種類ごとにカードが並びます。

:::tip
ファイルやフォルダーをウィンドウのどこかにドロップすると文字起こしできます。
:::

## ファイルを文字起こしする

1. 上部のバーで **ファイル** をクリックし（または `Ctrl+O`、macOS では `⌘O`）、音声または動画ファイルを選ぶか、ウィンドウにドロップします。次に **続行** をクリックします。
2. 設定を確認します。ほとんどの音声は既定値のままで問題ありません。
   - **エンジン**: お使いのコンピューターで動作する WhisperX。コンピューターが遅い場合は、小さめの**モデル**（`small` など）を選びます。
   - **言語**: **音声の言語** は自動で検出されます。わかっている場合は選ぶと誤りを防げます。翻訳するには、別の**文字起こしの言語**を選びます。
   - **コンテキスト** と **オプション**: 話者の識別など、任意のヒントと機能です。

   すべての設定は[文字起こしの設定](/ja/guides/transcription-settings/)をご覧ください。
3. **文字起こしを開始** をクリックします（または `Ctrl+Enter`、macOS では `⌘↩`）。

処理中は各ステップ（モデルの読み込み、文字起こし、単語の位置合わせ…）の進捗が表示されます。その間も Audiotext を使い続けられます。結果は履歴に保存され、完了すると開きます。キャンセルするには **キャンセル** をクリックするか `Esc` を押します。

ほかの文字起こしが実行中の場合、ボタンは **キューに追加** に変わり、現在の処理が終わると新しい文字起こしが始まります。

## 結果を読んで使う

完了すると文字起こしが開きます。

- 文をクリックすると、その位置から音声を再生します。
- **トランスクリプト**、**プレーンテキスト**、**要約** を切り替えます。
- **翻訳**、**コピー**、**エクスポート** で、翻訳、コピー、ファイルへの保存ができます。

できることのすべては[トランスクリプト](/ja/guides/transcript/)をご覧ください。

## キーボードショートカット

| ショートカット | 操作 |
| --- | --- |
| `Ctrl+Enter` / `⌘↩` | 文字起こしを開始、または録音の開始と停止 |
| `Ctrl+O` / `⌘O` | ファイルを選択（フォルダーソースではフォルダー） |
| `Ctrl+S` / `⌘S` | 表示中の文字起こしをエクスポート |
| `Ctrl+F` / `⌘F` | 文字起こし内を検索 |
| `Esc` | 実行中の文字起こしをキャンセル |
| `Space` | 音声を再生・一時停止 |
| `←` / `→` | 5 秒戻る・進む |
