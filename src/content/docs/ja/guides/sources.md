Audiotext は 4 種類のソースから文字起こしします。ソースは上部のバーの **新しい文字起こし** で選びます。

## ファイル

音声または動画ファイルを文字起こしします。**ファイルを選択…** をクリックするか、ファイルをウィンドウにドロップします。ファイル選択画面は既定で **サポートされているすべてのファイル** を表示しますが、**音声ファイル** や **動画ファイル** だけを表示することもできます。対応形式は[形式と言語](/ja/reference/formats-and-languages/)をご覧ください。

一度に追加できるファイルは 1 つだけです。複数のファイルを文字起こしするには、[フォルダー](#フォルダー)ソースを使います。

## URL

**YouTube 動画** や **音声・動画ファイルへの直接リンク**（ポッドキャストのエピソードなど）を文字起こしします。URL を貼り付け（**貼り付け** または `Ctrl+V`）、**続行** をクリックします。URL は `http://` または `https://` で始まる必要があります。

```text
https://youtu.be/dQw4w9WgXcQ
https://example.com/podcast/episode-12.mp3
```

最初に音声がダウンロードされるため、インターネット接続が必要です。

## マイク

自分の声や会議を録音して文字起こしします。録音は履歴に残るので、後で再生できます。

1. 一覧からマイクを選びます（接続したばかりの場合は更新ボタンをクリックします）。
2. 録音ボタンをクリックして（または `Ctrl+Enter`、macOS では `⌘↩`）録音を始めます。レベルメーターが、音が小さすぎる、**適切なレベル**、大きすぎる、のいずれかを示します。
3. もう一度クリックすると録音を止めて文字起こしします。

### ライブテキスト

**WhisperX** では、**ライブテキスト** カードの **録音中にテキストを表示** をオンにすると、話している間にテキストの下書きが表示されます。下書きは高速な**ライブ用モデル**（既定は `small`）が書きます。録音を止めると、録音全体がより正確なエンジンのモデルで改めて文字起こしされ、下書きが置き換えられます。

![マイクで録音中のライブテキスト](/screenshots/live-text.png)

:::caution
システムが入力デバイスを認識し、アプリにその使用を許可している必要があります。そうでない場合は **マイクが見つかりません** と表示されます。macOS では **システム設定** → **プライバシーとセキュリティ** → **マイク** で Audiotext を許可してください。
:::

### パソコンの音声を録音する

パソコンで再生している音声（ビデオ通話、ウェビナー、ダウンロードできない動画など）を文字起こしするには、スピーカーの音を入力に送るデバイスから録音します。一度設定したら、更新ボタンをクリックし、マイクの一覧から選びます。パソコンで再生されるものはすべて（通知音も含めて）録音されますが、あなたの声は録音されません。

- **Windows**: `mmsys.cpl` を実行し、**録音** タブで一覧を右クリックして無効なデバイスを表示し、**ステレオ ミキサー** を有効にします。サウンドカードにない場合は [VB-CABLE](https://vb-audio.com/Cable/) をインストールし、**CABLE Input** を出力デバイスにして、Audiotext で **CABLE Output** を選びます。音を聞き続けるには、**CABLE Output** のプロパティで **このデバイスを聴く** をオンにします。
- **macOS**: [BlackHole](https://existential.audio/blackhole/) をインストールし（`brew install blackhole-2ch`）、Audiotext で **BlackHole 2ch** を選びます。音を聞き続けるには、スピーカーと BlackHole で [複数出力装置](https://github.com/ExistentialAudio/BlackHole/wiki/Multi-Output-Device) を作成し、それを出力デバイスにします。
- **Linux**（PulseAudio または PipeWire）: Audiotext で **pulse** を選び、録音を開始します。次に `pavucontrol` の **録音** タブで、Audiotext のソースをスピーカーのモニターに変更します。

## フォルダー

フォルダー内のすべての音声ファイルと動画ファイルを文字起こしします。**フォルダー** カードで **サブフォルダーを含める** がオンの場合は、サブフォルダー内のファイルも対象です。**フォルダーを選択…** をクリックするか、フォルダーをウィンドウにドロップします。見つかったファイルの数が表示されます。一部のファイルを除外するには、その名前またはパスをカンマ区切りで **次に一致するファイルをスキップ** に入力します（例: `*.wav, drafts/*`）。隠しファイルは常にスキップされます。

各ファイルの文字起こしは、そのファイルの隣（または **出力** カードで選んだ別のフォルダー）に、同じ名前と、選んだ各**ファイルの種類**の拡張子で保存されます。たとえば `.txt` と `.vtt` の場合は次のとおりです。

```text
files-to-transcribe
├── paranoid-android.mp3
├── paranoid-android.txt
├── paranoid-android.vtt
└── movies
    ├── mulholland-dr.avi
    ├── mulholland-dr.txt
    └── mulholland-dr.vtt
```

名前が同じで拡張子が異なる 2 つのファイル（例: `talk.mp3` と `talk.mp4`）がある場合、互いに上書きしないように、文字起こしの名前に拡張子が残ります（`talk.mp3.txt` と `talk.mp4.txt`）。

すでに文字起こしがあるファイルは **スキップ** されます。ファイルがスキップされるのは、選択したすべてのファイル形式がそろっている場合だけなので、ファイル形式を追加するとそのファイルはもう一度文字起こしされます。文字起こしできないファイルがあっても、残りのファイルは文字起こしされます。

### フォルダーのファイル

履歴にあるフォルダーのページには、そのファイルが一覧表示され、それぞれの状態、長さ、サイズ、テキストのプレビューが表示されます。ファイルを検索したり、状態（**すべて**、**完了**、**失敗**、**未完了**）で絞り込んだり、名前、状態、長さ、サイズで並べ替えたりできます。移動または削除されたファイルには **ファイルが見つかりません** と表示されます。

- ファイルをクリックすると文字起こしが開きます。ファイルの `⋯` ボタンをクリック（または右クリック）すると、テキストのコピー、エクスポート・要約・翻訳を直接開く、ファイルマネージャーで表示、**このファイルを再文字起こし** ができます。
- `Ctrl`/`⌘` または `Shift` で複数のファイルを選択するか、`Ctrl+A` / `⌘A` で表示中のすべてのファイルを選択して、**再文字起こし**、**エクスポート…**（1 つの TXT、Markdown、Word ファイルにまとめて）、**履歴から削除…** を実行できます。`Enter` で選択したファイルを開き、`Esc` で選択を解除します。
- **失敗したものを再試行** は失敗したファイルをもう一度文字起こしします。**フォルダーを再スキャン** は新しいファイルなど、文字起こしのないファイルだけを文字起こしし、すでに文字起こしがあるためスキップしたファイルの数を表示します。
- フォルダーの `⋯` メニューでは、**すべて再文字起こし…**（すべてのファイルを再文字起こしして文字起こしを置き換え）、**すべてエクスポート…**（1 つのファイルに）、見つからないファイルの一覧からの削除、元のフォルダーや保存したファイルのフォルダーを開く操作ができます。
- フォルダーの設定を変更すると、別の設定（エンジン、モデル、言語など）で文字起こしされたファイルが **再文字起こし** ボタンとともに表示されます。

ヘッダーには、ファイルの保存先と元のフォルダーへのリンクが表示されます。**設定を編集** でフォルダーの設定を変更し、**保存して再スキャン** でその設定を使って文字起こしのないファイルを文字起こしします。

### フォルダーを監視する

**フォルダー** カードの **フォルダーを監視** をオンにすると、フォルダー（またはサブフォルダー）に追加されたファイルを、**監視を停止** をクリックするまで文字起こしし続けます。ボイスレコーダーや会議ツールの録音がフォルダーにコピーされる場合に便利です。

- フォルダーにすでにあるファイルはスキップされます。ただし **フォルダー内の既存のファイルを文字起こし** をオンにすると、文字起こしのないファイルが最初に文字起こしされます。
- ファイルは完全にコピーされてから（サイズが変わらなくなってから）文字起こしされるので、大きなファイルが途中まで文字起こしされることはありません。
- Audiotext を閉じたときに監視していたフォルダーは、次に開いたときに再び監視され、すでに確認したファイルの続きから処理されます。停止したフォルダーは **監視を再開** で再び監視できます。
- フォルダーが利用できない場合（例: 接続されていないドライブにある場合）、Audiotext は失敗せずにフォルダーを待ちます。
- ほかの文字起こしや録音を行うときは、フォルダーの監視が一時停止され（停止するまで新しい文字起こしには **開始しています…** と表示されます）、終わると再開されます。
- エラーが発生しても監視は止まりません。また、まとめて文字起こしされたファイルは 1 つの通知で知らされます。

## キュー

ほかの文字起こしの実行中でも新しい文字起こしを設定できます。ボタンが **キューに追加** に変わり、現在の処理が終わると始まります。待機中と実行中の文字起こしは履歴に表示されます。
