[履歴](/ja/guides/history/)で文字起こしを選ぶと開きます。ツールバーで **トランスクリプト**、**プレーンテキスト**、**要約** の 3 つのモードを切り替えられ、**翻訳**、**コピー**、**エクスポート** のボタンがあります。

## トランスクリプトモード

各文をタイムスタンプとともに表示し、話者を識別した場合は話者も表示します。

タイムスタンプが使えるのは **WhisperX** と、**Whisper API** の `whisper-1` および `gpt-4o-transcribe-diarize` モデルだけです。タイムスタンプがない場合は文単位で再生できないので、代わりに **プレーンテキスト** モードを使います。

### 音声を再生する

- **文をクリック** すると、その位置から音声を再生します。再生中の文がハイライトされ、テキストが再生に合わせてスクロールします。単語ごとのタイミングがあれば、各単語もハイライトされます。
- プレーヤーバーで再生、一時停止、任意の位置への移動、**速度** の変更（`0.5×` から `2×`、声の高さは維持）ができます。
- キーボードショートカット: `Space` で再生・一時停止、`←`/`→` で 5 秒戻る・進む。

ソースファイルが移動または削除された場合、音声は利用できませんが、テキストは残ります。マイクの録音は Audiotext が保存しているので、いつでも再生できます。

### 字幕付きで動画を見る

動画の文字起こしでは、テキストの上に動画が表示されます。動画のメニューから **動画に字幕を表示** をオンにし、字幕の **サイズ**（小・中・大）、**位置**（下・上）、**スタイル**（暗い背景・縁取り）を選べます。

### 検索

`Ctrl+F`（macOS では `⌘F`）を押して入力します。`Enter` と `Shift+Enter` で次と前の一致に移動し、`Esc` で検索をクリアします。

## 文字起こしを修正する

タイムスタンプ（字幕と再生で使われます）を保ったまま文字起こしを修正するには、`⋯` メニューのオプションを使うか、文を右クリックします。

- **検索と置換…**: 文字起こし全体で単語や語句を置き換えます（綴りを間違えた名前など）。置換前に出現回数が表示され、**大文字と小文字を区別** することもできます。
- **話者の名前を変更…**: 各話者に名前を付けます（`SPEAKER_00` → `花子`）。2 人の話者に同じ名前を付けると統合されます。
- **テキストを編集…**: 文を右クリックしてテキストを変更します。
- **ここから再生**: 文を右クリックして再生します。

変更されなかった単語はタイミングが保たれるので、再生中も引き続きハイライトされます。

## プレーンテキスト

**プレーンテキスト** モードでは、テキストエディターのように自由にテキストを編集できます。変更は自動で保存されます。トランスクリプトは元のテキストとタイムスタンプを保持するため、字幕にはプレーンテキストの編集は反映されません。

## コピーとエクスポート

**コピー** は現在のモードのテキスト（トランスクリプト、要約、翻訳）をコピーします。

**エクスポート**（または `Ctrl+S`、macOS では `⌘S`）で、文字起こしを次の形式で保存します。

| 形式 | 内容 |
| --- | --- |
| プレーンテキスト (`.txt`) | テキスト |
| Markdown (`.md`) | 要約（ある場合）と、段落ごとのタイムスタンプと話者付きのテキスト |
| Word 文書 (`.docx`) | Markdown と同じ内容で、編集や印刷にそのまま使えます |
| 字幕 (`.srt`) | 動画プレーヤー用の字幕 |
| Web 字幕 (`.vtt`) | Web 用の字幕 |
| 表 (`.tsv`) | 1 文 1 行で、開始と終了（ミリ秒）とテキスト |
| JSON (`.json`) | テキスト、タイムスタンプ・単語・話者付きのセグメント、要約（ある場合） |

字幕と表にはタイムスタンプが必要です。

## 名前の変更、タグ、メモ

文字起こしのヘッダーには、名前、ソース、日付、タグが表示されます。名前をダブルクリックすると変更でき、タグをクリックすると変更でき、**メモを追加** をクリックするとメモを書けます。その他のオプションは[履歴](/ja/guides/history/)にあります。
