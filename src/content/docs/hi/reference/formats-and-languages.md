## ऑडियो और वीडियो फ़ॉर्मेट

Audiotext FFmpeg से वीडियो फ़ाइलों का ऑडियो निकालता है, इसलिए यह दोनों को ट्रांसक्राइब करता है।

**ऑडियो**: `.aac`, `.flac`, `.mp3`, `.mpeg`, `.oga`, `.ogg`, `.opus`, `.wav`, `.wma`

**वीडियो**: `.3g2`, `.3gp`, `.3gp2`, `.3gpp`, `.3gpp2`, `.asf`, `.avi`, `.f4a`, `.f4b`, `.f4v`, `.flv`, `.m4a`, `.m4b`, `.m4r`, `.m4v`, `.mkv`, `.mov`, `.mp4`, `.ogv`, `.ogx`, `.webm`, `.wmv`

## आउटपुट फ़ॉर्मेट

| फ़ॉर्मेट | निर्यात | फ़ोल्डर (WhisperX) | फ़ोल्डर (Whisper API) |
| --- | :---: | :---: | :---: |
| सादा टेक्स्ट (`.txt`) | ✓ | ✓ | `text` |
| Markdown (`.md`) | ✓ | ✗ | ✗ |
| Word दस्तावेज़ (`.docx`) | ✓ | ✗ | ✗ |
| सबटाइटल (`.srt`) | ✓ | ✓ | `srt` |
| वेब सबटाइटल (`.vtt`) | ✓ | ✓ | `vtt` |
| तालिका (`.tsv`) | ✓ | ✓ | ✗ |
| JSON (`.json`) | ✓ | ✓ | `json`, `verbose_json` |
| Audacity लेबल (`.aud`) | ✗ | ✓ | ✗ |

[निर्यात](/hi/guides/transcript/#कॉपी-और-निर्यात) और [आउटपुट कार्ड](/hi/guides/transcription-settings/#फ़ोल्डर-और-आउटपुट) देखें।

अफ़्रीकांस, अल्बानियाई, अम्हारिक, अरबी, अर्मेनियाई, असमिया, अज़रबैजानी, बश्किर, बास्क, बेलारूसी, बंगाली, बोस्नियाई, ब्रेटन, बल्गेरियाई, बर्मी, कैटलन, चीनी, चीनी (कैंटोनीज़), क्रोएशियाई, चेक, डेनिश, डच, अंग्रेज़ी, एस्टोनियाई, फ़ैरोइज़, फ़ारसी, फ़िनिश, फ़्रेंच, गैलिशियन, जॉर्जियाई, जर्मन, ग्रीक, गुजराती, हैतियन क्रियोल, हौसा, हवाईयन, हिब्रू, हिन्दी, हंगेरियाई, आइसलैंडिक, इंडोनेशियाई, इतालवी, जापानी, जावानीज़, कन्नड़, कज़ाख, ख़्मेर, कोरियाई, लाओ, लैटिन, लातवियाई, लिंगाला, लिथुआनियाई, लक्ज़मबर्गिश, मैसेडोनियाई, मालागासी, मलय, मलयालम, माल्टीज़, माओरी, मराठी, मंगोलियाई, नेपाली, नॉर्वेजियन, नॉर्वेजियन नीनोर्स्क, ऑक्सिटन, पश्तो, पोलिश, पुर्तगाली, पंजाबी, रोमानियाई, रूसी, संस्कृत, सर्बियाई, शोना, सिंधी, सिंहली, स्लोवाक, स्लोवेनियाई, सोमाली, स्पैनिश, सुंडानी, स्वाहिली, स्वीडिश, टैगालॉग, ताजिक, तमिल, तातार, तेलुगु, थाई, तिब्बती, तुर्की, तुर्कमेन, यूक्रेनियाई, उर्दू, उज़्बेक, वियतनामी, वेल्श, यिडिश और योरूबा।

गुणवत्ता भाषा पर निर्भर करती है: यह अंग्रेज़ी, स्पैनिश, फ़्रेंच, जर्मन, पुर्तगाली, इतालवी या जापानी जैसी सबसे ज़्यादा बोली जाने वाली भाषाओं में सबसे अच्छी होती है।

## इंटरफ़ेस की भाषाएँ

Audiotext का इंटरफ़ेस, और यह दस्तावेज़, इन भाषाओं में उपलब्ध हैं:

| भाषा | | भाषा | |
| --- | --- | --- | --- |
| Català | कैटलन | Polski | पोलिश |
| Čeština | चेक | Português | पुर्तगाली |
| Deutsch | जर्मन | Română | रोमानियाई |
| English | अंग्रेज़ी | Русский | रूसी |
| Español | स्पैनिश | Svenska | स्वीडिश |
| Français | फ़्रेंच | Türkçe | तुर्की |
| Galego | गैलिशियन | Українська | यूक्रेनियाई |
| हिन्दी | हिन्दी | Tiếng Việt | वियतनामी |
| Bahasa Indonesia | इंडोनेशियाई | 简体中文 | सरलीकृत चीनी |
| Italiano | इतालवी | 日本語 | जापानी |
| Nederlands | डच | 한국어 | कोरियाई |

इसे **प्राथमिकताएँ** → **सामान्य** → **इंटरफ़ेस की भाषा** में बदलें। किसी अनुवाद को बेहतर बनाने या भाषा जोड़ने के लिए [योगदान](/hi/help/contributing/#इंटरफ़ेस-का-अनुवाद-करें) देखें।
