Audiotext आपका डेटा आपके कंप्यूटर पर रखता है। जब तक आप कोई दूरस्थ इंजन (Whisper API या Google API) या Ollama के अलावा कोई AI प्रदाता उपयोग नहीं करते, तब तक कुछ भी कहीं नहीं भेजा जाता।

## उपयोगकर्ता कॉन्फ़िगरेशन फ़ोल्डर

सेटिंग्स, इतिहास और रिकॉर्डिंग आपके उपयोगकर्ता कॉन्फ़िगरेशन फ़ोल्डर में सहेजी जाती हैं, इसलिए वे अपडेट के बाद भी बनी रहती हैं:

| सिस्टम | फ़ोल्डर |
| --- | --- |
| Windows | `%APPDATA%\Audiotext` |
| macOS | `~/Library/Application Support/Audiotext` |
| Linux | `~/.config/audiotext` (या `$XDG_CONFIG_HOME/audiotext`) |

इसमें होता है:

- `config.ini`: आपकी सेटिंग्स। डिफ़ॉल्ट वापस लाने के लिए इसे हटा दें।
- `history.json`: आपके ट्रांसक्रिप्शन, उनके सारांश, अनुवाद और सुधारों के साथ।
- `media/`: माइक्रोफ़ोन रिकॉर्डिंग और URL से डाउनलोड किया गया ऑडियो, ताकि उन्हें बाद में चलाया जा सके। उनका ट्रांसक्रिप्शन इतिहास से हटाने पर ये भी हट जाते हैं।

किसी दूसरे फ़ोल्डर का उपयोग करने के लिए, जैसे पोर्टेबल इंस्टॉलेशन में, `AUDIOTEXT_CONFIG_DIR` एनवायरनमेंट वेरिएबल सेट करें।

:::note
ऐप फ़ोल्डर की `config.ini` फ़ाइल में डिफ़ॉल्ट सेटिंग्स होती हैं और इसे कभी बदला नहीं जाता।
:::

## API कुंजियाँ

API कुंजियाँ और Hugging Face टोकन आपके सिस्टम के क्रेडेंशियल स्टोर में रखे जाते हैं:

- **macOS**: Keychain।
- **Windows**: Credential Manager।
- **Linux**: Secret Service (जैसे GNOME Keyring या KWallet)।

अगर सिस्टम में ऐसा कोई स्टोर नहीं है (जैसे डेस्कटॉप के बिना कोई सर्वर), तो ये कॉन्फ़िगरेशन फ़ोल्डर की एक `.env` फ़ाइल में सहेजी जाती हैं, जिसे केवल आपका उपयोगकर्ता पढ़ सकता है। पिछले संस्करण जो कुंजियाँ इस फ़ाइल में सहेजते थे, वे ऐप के पहली बार खुलने पर क्रेडेंशियल स्टोर में ले जाई जाती हैं।

कुंजियों का उपयोग **केवल** हर सेवा के API को अनुरोध भेजने के लिए होता है।

## एनवायरनमेंट वेरिएबल

कुंजियों के नाम वाले एनवायरनमेंट वेरिएबल ऐप में सेट कुंजियों पर प्राथमिकता रखते हैं:

| वेरिएबल | सेवा |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI (Whisper API, सारांश, अनुवाद) |
| `ANTHROPIC_API_KEY` | Claude |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `GEMINI_API_KEY` | Gemini |
| `MISTRAL_API_KEY` | Mistral |
| `XAI_API_KEY` | Grok (xAI) |
| `DEEPL_API_KEY` | DeepL |
| `GOOGLE_API_KEY` | Google Speech-to-Text और Google Translate |
| `HF_TOKEN` | Hugging Face (वक्ताओं की पहचान) |
| `AUDIOTEXT_CONFIG_DIR` | सेटिंग्स और इतिहास का फ़ोल्डर |

## मॉडल

WhisperX और वक्ता-पहचान के मॉडल पहली बार उपयोग होने पर डाउनलोड होते हैं और Hugging Face उन्हें `~/.cache/huggingface` (Windows पर `%USERPROFILE%\.cache\huggingface`) में कैश करता है। उनके द्वारा घेरी गई जगह खाली करने के लिए यह फ़ोल्डर हटा दें।
