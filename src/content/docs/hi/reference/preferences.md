**प्राथमिकताएँ** में वे सेटिंग्स हैं जो हर ट्रांसक्रिप्शन के साथ नहीं बदलतीं। इन्हें विंडो के ऊपर दाईं ओर गियर से खोलें। बदलाव अपने-आप सहेजे जाते हैं।

## सामान्य

- **रूप-रंग**: **सिस्टम** (आपके सिस्टम के अनुसार), **लाइट** या **डार्क**।
- **इंटरफ़ेस की भाषा**: Audiotext की भाषा, या **सिस्टम की भाषा**। कोई ट्रांसक्रिप्शन चल न रहा हो, तभी इसे बदला जा सकता है। [उपलब्ध भाषाएँ](/hi/reference/formats-and-languages/#इंटरफ़ेस-की-भाषाएँ) देखें।
- **सूचनाएँ**: ट्रांसक्रिप्शन तैयार होने पर सिस्टम की सूचना दिखाता है (फ़ोल्डर के लिए, जब उसकी सभी फ़ाइलें तैयार हो जाएँ, और निगरानी वाले फ़ोल्डर के लिए, हर बार जब कोई नई फ़ाइल तैयार हो)। डिफ़ॉल्ट रूप से चालू। macOS पर ये **Script Editor** से और Windows पर **Windows PowerShell** से आती हैं, इसलिए सिस्टम की सेटिंग्स में इन्हीं ऐप्स के लिए इन्हें अनुमति दी जाती है या बंद किया जाता है। Linux पर इनके लिए `notify-send` (पैकेज `libnotify-bin` या `libnotify`) ज़रूरी है।

## AI

[सारांश और अनुवाद](/hi/guides/summary-and-translation/) के प्रदाता:

- **सारांश** → **प्रदाता** और **मॉडल**।
- **अनुवाद** → **प्रदाता** और **मॉडल**। DeepL और Google Translate में चुनने के लिए मॉडल नहीं हैं।
- **Ollama** → **सर्वर URL**: Ollama का पता, डिफ़ॉल्ट `http://localhost:11434`।

प्रदाता का डिफ़ॉल्ट मॉडल उपयोग करने के लिए **मॉडल** खाली छोड़ दें। प्रदाता के बगल का बटन उसकी API कुंजी सेट करता है।

## API कुंजियाँ

हर सेवा की कुंजियाँ। कुंजी डालने के लिए **सेट करें…** पर, या उसे बदलने के लिए **बदलें…** पर क्लिक करें (हटाने के लिए खाली छोड़ दें)। ये आपके सिस्टम के क्रेडेंशियल स्टोर में रखी जाती हैं।

| कुंजी | किसके लिए |
| --- | --- |
| OpenAI API कुंजी | Whisper API, और OpenAI से सारांश व अनुवाद |
| Anthropic API कुंजी | Claude से सारांश और अनुवाद |
| DeepSeek API कुंजी | DeepSeek से सारांश और अनुवाद |
| Gemini API कुंजी | Gemini से सारांश और अनुवाद (Google AI Studio से) |
| Mistral API कुंजी | Mistral से सारांश और अनुवाद |
| xAI API कुंजी | Grok से सारांश और अनुवाद |
| DeepL API कुंजी | DeepL से अनुवाद (मुफ़्त प्लान की कुंजियाँ भी काम करती हैं) |
| Google API कुंजी | मुफ़्त टियर से आगे Google Speech-to-Text, और Google Translate (Cloud Translation API) |
| Hugging Face टोकन | WhisperX से वक्ताओं की पहचान |

:::caution
हर प्रदाता अपने API के उपयोग के लिए शुल्क लेता है, जिसके लिए Audiotext ज़िम्मेदार नहीं है। अगर नई कुंजी के साथ OpenAI `429` त्रुटि लौटाता है, तो [समस्या निवारण](/hi/help/troubleshooting/#whisper-api-429-त्रुटि-लौटाता-है) देखें।
:::

## WhisperX

**गणना प्रकार**, **बैच आकार** और **CPU का उपयोग करें**। [WhisperX के उन्नत विकल्प](/hi/reference/engines/#उन्नत-विकल्प) देखें।

## सबटाइटल

WhisperX से किसी फ़ोल्डर को ट्रांसक्राइब करते समय सहेजी जाने वाली `.srt` और `.vtt` फ़ाइलों के विकल्प:

- **शब्द हाइलाइट करें**: हर शब्द बोले जाते समय उसे रेखांकित करता है। डिफ़ॉल्ट रूप से बंद।
- **अधिकतम पंक्तियाँ**: हर सबटाइटल की अधिकतम पंक्तियाँ। डिफ़ॉल्ट `2`।
- **अधिकतम पंक्ति चौड़ाई**: पंक्ति तोड़ने से पहले उसमें अधिकतम अक्षर। डिफ़ॉल्ट `42`।
