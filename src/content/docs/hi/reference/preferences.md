**प्राथमिकताएँ** में वे सेटिंग्स हैं जो हर ट्रांसक्रिप्शन के साथ नहीं बदलतीं। इन्हें विंडो के ऊपर दाईं ओर गियर से खोलें। बदलाव अपने-आप सहेजे जाते हैं।

## सामान्य

- **रूप-रंग**: **सिस्टम** (आपके सिस्टम के अनुसार), **लाइट** या **डार्क**।
- **इंटरफ़ेस का आकार**: टेक्स्ट और नियंत्रणों का आकार, 80% से 200% तक। डिफ़ॉल्ट रूप से `100%`। बदलाव तुरंत लागू होता है।
- **इंटरफ़ेस की भाषा**: Audiotext की भाषा, या **सिस्टम की भाषा**। [उपलब्ध भाषाएँ](/hi/reference/formats-and-languages/#इंटरफ़ेस-की-भाषाएँ) देखें।
- **तारीख़ का प्रारूप**: इंटरफ़ेस की भाषा में ट्रांसक्रिप्शन की तारीख़ें कैसे दिखें: छोटा (`4/10/26`), मध्यम (`4 अक्टू॰ 2026`, डिफ़ॉल्ट), लंबा (`4 अक्टूबर 2026`) या ISO (`2026-10-04`)। मेनू हर प्रारूप को एक उदाहरण के साथ दिखाता है।
- **समय का प्रारूप**: **स्वचालित** (इंटरफ़ेस की भाषा की घड़ी), 12 घंटे (`1:30 pm`) या 24 घंटे (`13:30`)।
- **सूचनाएँ**: ट्रांसक्रिप्शन तैयार होने पर सिस्टम की सूचना दिखाता है (फ़ोल्डर के लिए, जब उसकी सभी फ़ाइलें तैयार हो जाएँ, और निगरानी वाले फ़ोल्डर के लिए, हर बार जब नई फ़ाइलें तैयार हों, एक ही सूचना में)। डिफ़ॉल्ट रूप से चालू। macOS पर ये **Script Editor** से और Windows पर **Windows PowerShell** से आती हैं, इसलिए सिस्टम की सेटिंग्स में इन्हीं ऐप्स के लिए इन्हें अनुमति दी जाती है या बंद किया जाता है। Linux पर इनके लिए `notify-send` (पैकेज `libnotify-bin` या `libnotify`) ज़रूरी है।
- **अपडेट की अपने आप जाँच करें**: ऐप खुलने पर नए संस्करण की जाँच करता है और, अगर कोई हो, तो ऊपरी पट्टी में **संस्करण … उपलब्ध है** बटन दिखाता है, जो उसका डाउनलोड पेज खोलता है। प्री-रिलीज़ संस्करण नहीं दिए जाते। डिफ़ॉल्ट रूप से चालू।

## प्रदाता

[सारांश, प्रश्नों और अनुवाद](/hi/guides/summary-and-translation/) के प्रदाता:

- **सारांश** → **प्रदाता** और **मॉडल**।
- **पूछें** → **प्रदाता** और **मॉडल**: जो ट्रांसक्रिप्शन के बारे में प्रश्नों के उत्तर देते हैं। जब तक आप उन्हें न बदलें, वे सारांश वाले ही होते हैं।
- **अनुवाद** → **प्रदाता** और **मॉडल**। DeepL और Google Translate में चुनने के लिए मॉडल नहीं हैं।
- **Ollama** → **सर्वर URL**: Ollama का पता, डिफ़ॉल्ट `http://localhost:11434`।

प्रदाता का डिफ़ॉल्ट मॉडल उपयोग करने के लिए **मॉडल** खाली छोड़ दें। प्रदाता के बगल का बटन उसकी API कुंजी सेट करता है।

## API कुंजियाँ

हर सेवा की कुंजियाँ। कुंजी डालने के लिए **API कुंजी सेट करें…** पर, या उसे बदलने के लिए **API कुंजी बदलें…** पर क्लिक करें (हटाने के लिए खाली छोड़ दें)। ये आपके सिस्टम के क्रेडेंशियल स्टोर में रखी जाती हैं। इन्हें इनके उपयोग के अनुसार समूहों में रखा गया है, और जो कुंजियाँ सेट हैं उन पर सही का निशान दिखता है।

| समूह | कुंजी | किसके लिए |
| --- | --- | --- |
| **LLM प्रदाता** | OpenAI API कुंजी | Whisper API, और OpenAI से सारांश, प्रश्न व अनुवाद |
| | Anthropic API कुंजी | Claude से सारांश, प्रश्न और अनुवाद |
| | DeepSeek API कुंजी | DeepSeek से सारांश, प्रश्न और अनुवाद |
| | Gemini API कुंजी | Gemini से सारांश, प्रश्न और अनुवाद (Google AI Studio से) |
| | Mistral API कुंजी | Mistral से सारांश, प्रश्न और अनुवाद |
| | xAI API कुंजी | Grok से सारांश, प्रश्न और अनुवाद |
| **अनुवाद** | DeepL API कुंजी | DeepL से अनुवाद (मुफ़्त प्लान की कुंजियाँ भी काम करती हैं) |
| | Google API कुंजी | मुफ़्त टियर से आगे Google Speech-to-Text, और Google Translate (Cloud Translation API) |
| **ट्रांसक्रिप्शन** | Hugging Face टोकन | WhisperX से वक्ताओं की पहचान |

:::caution
हर प्रदाता अपने API के उपयोग के लिए शुल्क लेता है, जिसके लिए Audiotext ज़िम्मेदार नहीं है। अगर नई कुंजी के साथ OpenAI `429` त्रुटि लौटाता है, तो [समस्या निवारण](/hi/help/troubleshooting/#whisper-api-429-त्रुटि-लौटाता-है) देखें।
:::

## ट्रांसक्रिप्शन

इंजनों के विकल्प, हर एक अपने अलग अनुभाग में।

### WhisperX

**गणना प्रकार**, **बैच आकार** और **CPU का उपयोग करें**। [WhisperX के उन्नत विकल्प](/hi/reference/engines/#उन्नत-विकल्प) देखें। Apple Silicon वाले Mac पर WhisperX उसके GPU पर ट्रांसक्राइब करता है, जब तक **CPU का उपयोग करें** चालू न हो। [Mac पर](/hi/reference/engines/#mac-पर) देखें। Mac के GPU पर **गणना प्रकार** और **बैच आकार** के संकेत बताते हैं कि वे लागू नहीं होते, और **CPU का उपयोग करें** में **समर्थित मॉडल** का लिंक होता है।

### Whisper API

**तापमान** और **शब्दों के टाइमस्टैम्प**। [Whisper API के विकल्प](/hi/reference/engines/#विकल्प) देखें।

## सबटाइटल

सबटाइटल कैसे बाँटे जाते हैं: वीडियो पर और **सबटाइटल** मोड में दिखने वाले, निर्यात की गई सबटाइटल फ़ाइलें और [सबटाइटल वाले वीडियो](/hi/guides/transcript/#सबटाइटल-के-साथ-वीडियो-निर्यात-करें)। हर विकल्प का एक मान क्षैतिज वीडियो के लिए और दूसरा वर्टिकल वीडियो (चौड़ाई से ज़्यादा ऊँचे, जैसे फ़ोन के लिए) के लिए है, जो ज़्यादा संकरे होते हैं:

| विकल्प | क्षैतिज | वर्टिकल |
| --- | :---: | :---: |
| **प्रति सबटाइटल अधिकतम पंक्तियाँ** | `2` | `2` |
| **प्रति पंक्ति अधिकतम अक्षर** | `42` | `24` |
| **चीनी, जापानी और कोरियाई**: इन भाषाओं में प्रति पंक्ति अक्षर, जिनके अक्षर लैटिन अक्षरों से लगभग दोगुने चौड़े होते हैं | `16` | `10` |

किसी सबटाइटल की पंक्तियाँ बराबर की जाती हैं, और बिना स्पेस के लिखी जाने वाली भाषाएँ अक्षरों के बीच तोड़ी जाती हैं।

**शब्द हाइलाइट करें** `.srt` और `.vtt` फ़ाइलों में हर शब्द बोले जाते समय उसे रेखांकित करता है। डिफ़ॉल्ट रूप से बंद।

## परिचय

Audiotext का संस्करण और इस दस्तावेज़, GitHub पर सोर्स कोड और दान पेज के लिंक। **अपडेट की जाँच करें** तुरंत नए संस्करण की जाँच करता है: अगर कोई हो, तो बटन **डाउनलोड करें** बन जाता है और उसका पेज खोलता है।
