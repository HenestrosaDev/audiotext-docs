Audiotext **Windows**, **macOS** और **Linux** के लिए एक डेस्कटॉप ऐप है। यह फ़ाइलों, YouTube वीडियो और माइक्रोफ़ोन रिकॉर्डिंग की आवाज़ को टेक्स्ट में बदलता है, और उसका अनुवाद, सारांश और सबटाइटल भी बना सकता है।

## ऐप डाउनलोड करें

GitHub पर [नवीनतम रिलीज़](https://github.com/HenestrosaDev/audiotext/releases/latest) से अपने सिस्टम की फ़ाइल डाउनलोड करें:

| सिस्टम | फ़ाइल |
| --- | --- |
| Windows (64-बिट) | `Audiotext-<version>-windows-x64-setup.exe` |
| macOS 15 या नया (Apple Silicon) | `Audiotext-<version>-macos-arm64.dmg` |
| Linux (x86_64) | `Audiotext-<version>-linux-x86_64.tar.gz` |

ऐप में उसकी ज़रूरत की हर चीज़ शामिल है, FFmpeg भी।

### Windows

इंस्टॉलर चलाएँ और उसके चरणों का पालन करें। इसके लिए एडमिनिस्ट्रेटर अनुमति की ज़रूरत नहीं है। अगर आपके पास NVIDIA GPU है, तो NVIDIA GPU (CUDA) के उपयोग का विकल्प चुनें: तब इंस्टॉलर GPU ऐड-ऑन डाउनलोड करता है, जो WhisperX को कहीं ज़्यादा तेज़ बनाता है। इंस्टॉलर साइन किया हुआ नहीं है, इसलिए Windows SmartScreen चेतावनी दिखा सकता है: अधिक जानकारी खोलें और फिर भी चलाने का विकल्प चुनें।

### macOS

`.dmg` फ़ाइल खोलें और **Audiotext** को **Applications** फ़ोल्डर में खींचें। ऐप Apple द्वारा नोटराइज़ नहीं है, इसलिए macOS पहली बार खोलने पर इसे रोक देता है: **System Settings** → **Privacy & Security** में जाएँ और Audiotext वाले संदेश के पास **Open Anyway** पर क्लिक करें। macOS पर CUDA उपलब्ध नहीं है, इसलिए WhisperX CPU पर चलता है। Intel वाले Mac समर्थित नहीं हैं, क्योंकि PyTorch अब उन्हें सपोर्ट नहीं करता।

### Linux

आर्काइव को निकालें और टर्मिनल से इंस्टॉलर चलाएँ:

```bash
tar -xzf Audiotext-<version>-linux-x86_64.tar.gz
cd Audiotext-<version>-linux-x86_64
./install.sh
```

यह Audiotext को आपके उपयोगकर्ता के लिए इंस्टॉल करता है और ऐप्लिकेशन मेनू में जोड़ता है (इसे `audiotext` कमांड से भी खोला जा सकता है)। NVIDIA GPU मिलने पर यह GPU ऐड-ऑन डाउनलोड करने का विकल्प देता है। बिना पूछे चुनने के लिए `./install.sh --gpu` या `./install.sh --cpu`, और अनइंस्टॉल करने के लिए `./install.sh --uninstall` चलाएँ (आपकी सेटिंग्स बनी रहती हैं)।

:::tip
GPU ऐड-ऑन का डाउनलोड Windows पर लगभग 2 GB और Linux पर 4 GB है, इसलिए यह केवल NVIDIA GPU होने पर ही उपयोगी है। इसके बिना WhisperX CPU पर चलता है, और Whisper API व Google API वैसे ही काम करते हैं। बाद में CPU और GPU संस्करण के बीच बदलने के लिए, ऐप को फिर से इंस्टॉल करें और दूसरा विकल्प चुनें।
:::

:::note
जब आप पहली बार **WhisperX** (डिफ़ॉल्ट इंजन) से ट्रांसक्राइब करते हैं, तो उसका मॉडल डाउनलोड होता है। इसका आकार `tiny` के लिए ~75 MB से लेकर `large-v2` के लिए ~3 GB तक है, इसलिए इसमें कुछ समय लग सकता है। इसके बाद के ट्रांसक्रिप्शन तुरंत शुरू होते हैं।
:::

## आवश्यकताएँ

- **WhisperX** आपके कंप्यूटर पर चलता है। यह किसी भी CPU पर काम करता है, लेकिन CUDA वाले NVIDIA GPU पर कहीं ज़्यादा तेज़ है। अपने हार्डवेयर के अनुसार मॉडल चुनने के लिए [इंजन](/hi/reference/engines/) देखें।
- **Whisper API** और **Google API** दूरस्थ सर्वरों पर चलते हैं, इसलिए उन्हें इंटरनेट कनेक्शन चाहिए, लेकिन शक्तिशाली हार्डवेयर नहीं।
- माइक्रोफ़ोन से ट्रांसक्राइब करने के लिए आपके सिस्टम को इनपुट डिवाइस पहचानना चाहिए।
- Linux पर रिकॉर्डिंग और प्लेबैक के लिए [PortAudio](https://www.portaudio.com/) चाहिए (Ubuntu या Debian पर `sudo apt install libportaudio2`)।

## ऐप अपडेट करें

नया संस्करण जारी होने पर Audiotext ऊपरी पट्टी में **संस्करण … उपलब्ध है** बटन दिखाता है। रिलीज़ का पेज खोलने के लिए उस पर क्लिक करें, अपने सिस्टम की फ़ाइल डाउनलोड करें और उसे पहली बार की तरह इंस्टॉल करें: Windows पर नया इंस्टॉलर चलाएँ, macOS पर नए ऐप को **Applications** फ़ोल्डर में खींचें, या Linux पर नए आर्काइव का `install.sh` चलाएँ। पिछला संस्करण बदल दिया जाता है, और आपकी सेटिंग्स और इतिहास बने रहते हैं, क्योंकि वे आपके [उपयोगकर्ता कॉन्फ़िगरेशन फ़ोल्डर](/hi/reference/files-and-data/#उपयोगकर्ता-कॉन्फ़िगरेशन-फ़ोल्डर) में सहेजे जाते हैं। अगर आप GPU ऐड-ऑन का उपयोग करते हैं, तो इंस्टॉल करते समय उसे फिर से चुनें।

खुद नए संस्करण की जाँच करने के लिए **प्राथमिकताएँ** → **परिचय** → **अपडेट की जाँच करें** खोलें। ऐप खुलने पर जाँच बंद करने के लिए **सामान्य** → **अपडेट** बंद करें।

## इंटरफ़ेस की भाषा बदलें

Audiotext उपलब्ध होने पर आपके सिस्टम की भाषा का उपयोग करता है। इसे बदलने के लिए **प्राथमिकताएँ** (ऊपर दाईं ओर गियर) खोलें और **सामान्य** → **इंटरफ़ेस की भाषा** में भाषा चुनें।
