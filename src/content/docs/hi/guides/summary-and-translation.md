ट्रांसक्रिप्शन तैयार होने के बाद Audiotext किसी भाषा मॉडल या अनुवाद सेवा से उसका सारांश और अनुवाद बना सकता है। दोनों इतिहास में रखे जाते हैं, इसलिए केवल एक बार बनाए जाते हैं।

## सारांश

किसी ट्रांसक्रिप्शन का **सारांश** मोड खोलें और **सारांश बनाएँ** पर क्लिक करें। भाषा मॉडल लिखता है:

- ट्रांसक्रिप्शन का **सारांश**।
- उसके **मुख्य बिंदु**।
- उसके **अध्याय**, अगर टाइमस्टैम्प हों। किसी अध्याय की शुरुआत से ऑडियो चलाने के लिए उस पर क्लिक करें।

**फिर से बनाएँ** इसे दोबारा लिखता है (जैसे दूसरा मॉडल चुनने के बाद)। **कॉपी करें** इसे कॉपी करता है, और Markdown व Word [निर्यात](/hi/guides/transcript/#कॉपी-और-निर्यात) में यह शामिल होता है।

अगर प्रदाता की API कुंजी सेट नहीं है, तो **सारांश** मोड उसे सेट करने का विकल्प देता है। बहुत लंबे ट्रांसक्रिप्शन (लगभग तीन घंटे या उससे ज़्यादा भाषण) का सारांश केवल उनकी शुरुआत से बनाया जाता है।

## अनुवाद

**अनुवाद करें** पर क्लिक करें, **इस भाषा में अनुवाद करें** में भाषा और **प्रदाता** चुनें, और पुष्टि करें। अनुवाद मूल टेक्स्ट के दाईं ओर एक पैनल में दिखता है।

- अगर ट्रांसक्रिप्शन में टाइमस्टैम्प हैं, तो हर सेगमेंट का अलग से अनुवाद होता है, इसलिए अनुवाद उन्हीं टाइमस्टैम्प से शुरू होता है: यह चल रहे सेगमेंट को हाइलाइट करता है, और किसी सेगमेंट पर क्लिक करने से वह चलता है।
- अगर आपने सादा टेक्स्ट संपादित किया है, तो उसकी जगह संपादित टेक्स्ट का अनुवाद होता है, बिना टाइमस्टैम्प के।
- दोनों टेक्स्ट के बीच के हैंडल को खींचकर उनका आकार बदलें, या आकार रीसेट करने के लिए उस पर डबल-क्लिक करें।
- **अनुवाद करें** बटन से आप **अनुवाद छिपाएँ**, **किसी दूसरी भाषा में अनुवाद करें…** या **अनुवाद हटाएँ** भी चुन सकते हैं।

### अनुवाद सुधारें और उसका समय बदलें

अनुवाद को अक्सर मूल से अलग समय की ज़रूरत होती है, जैसे ऐसे सबटाइटल जिन्हें पढ़ने में ज़्यादा समय लगता है। अनुवाद के किसी सेगमेंट पर राइट-क्लिक करके:

- **टेक्स्ट संपादित करें…**: उसका टेक्स्ट बदलें।
- **समय संपादित करें…**: मिलीसेकंड तक बदलें कि वह कब शुरू और खत्म होता है। समय `00:01:05,900`, `01:05,9` या `65.9` की तरह लिखें।
- **इसके बाद एक सेगमेंट जोड़ें…**: एक सेगमेंट जोड़ें, जो डिफ़ॉल्ट रूप से अगले सेगमेंट तक की खाली जगह भरता है।
- **सेगमेंट हटाएँ**।

### खुद अनुवाद करें

अनुवाद खुद लिखने के लिए **प्रदाता** में **स्वयं, शुरू से** चुनें। इसके लिए किसी API कुंजी की ज़रूरत नहीं है। अनुवाद ट्रांसक्रिप्शन के टाइमस्टैम्प और खाली सेगमेंट के साथ शुरू होता है, जो **अभी तक अनुवाद नहीं हुआ** के रूप में दिखते हैं, और पैनल बताता है कि कितने बाकी हैं। किसी पर राइट-क्लिक करके **टेक्स्ट का अनुवाद करें…** चुनें: डायलॉग उस दौरान बोला गया मूल टेक्स्ट दिखाता है।

### सबटाइटल और निर्यात

- वीडियो के ट्रांसक्रिप्शन में, अनुवाद को सबटाइटल के रूप में दिखाने के लिए **अनुवाद करें** मेनू में **इसे वीडियो के सबटाइटल के रूप में दिखाएँ** चुनें। वीडियो का मेनू भी उन्हें बदलता है। देखें [सबटाइटल के साथ वीडियो देखें](/hi/guides/transcript/#सबटाइटल-के-साथ-वीडियो-देखें)।
- अनुवाद को फ़ाइल के रूप में सहेजने के लिए **निर्यात करें** मेनू में अनुवाद वाला विकल्प चुनें, या अनुवाद के निर्यात बटन पर क्लिक करें। यह ट्रांसक्रिप्शन वाले ही [प्रारूपों](/hi/guides/transcript/#कॉपी-और-निर्यात) में निर्यात होता है, फ़ाइल के नाम में उसकी भाषा के साथ (जैसे `video.es.srt`), ताकि वीडियो प्लेयर उसे वीडियो के साथ लोड करें। जिन सेगमेंट का अभी तक अनुवाद नहीं हुआ, वे सबटाइटल में शामिल नहीं होते।

:::tip
बिना प्रदाता के सीधे किसी दूसरी भाषा में ट्रांसक्रिप्शन पाने के लिए, आप ट्रांसक्राइब करते समय भी अनुवाद कर सकते हैं। [भाषा](/hi/guides/transcription-settings/#भाषा) देखें।
:::

## प्रदाता

प्रदाता **प्राथमिकताएँ** → **AI** में चुने जाते हैं, सारांश और अनुवाद के लिए अलग-अलग।

| प्रदाता | डिफ़ॉल्ट मॉडल | API कुंजी |
| --- | --- | --- |
| OpenAI (डिफ़ॉल्ट) | `gpt-5.4-mini` | [OpenAI](https://platform.openai.com/api-keys) |
| Claude (Anthropic) | `claude-haiku-4-5` | [Anthropic](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [DeepSeek](https://platform.deepseek.com/api_keys) |
| Gemini (Google) | `gemini-3.8-flash` | [Google AI Studio](https://aistudio.google.com/apikey) |
| Mistral | `mistral-small-latest` | [Mistral](https://console.mistral.ai/api-keys) |
| Grok (xAI) | `grok-4.3` | [xAI](https://console.x.ai) |
| Ollama (लोकल) | `llama3.2` | ज़रूरी नहीं |

प्रदाता का डिफ़ॉल्ट मॉडल उपयोग करने के लिए **मॉडल** खाली छोड़ दें, या प्रदाता के किसी दूसरे मॉडल का नाम लिखें (जैसे `claude-sonnet-5-5` या `deepseek-reasoner`)।

अनुवाद इनसे भी किए जा सकते हैं:

- **DeepL**, जिसके लिए [DeepL API कुंजी](https://www.deepl.com/your-account/keys) चाहिए। मुफ़्त प्लान की कुंजियाँ भी काम करती हैं।
- **Google Translate**, जो Cloud Translation API सक्षम Google API कुंजी का उपयोग करता है।

### Ollama

[Ollama](https://ollama.com) मॉडल आपके कंप्यूटर पर चलाता है, बिना API कुंजी और बिना टेक्स्ट कहीं भेजे। इसे इंस्टॉल करें, कोई मॉडल डाउनलोड करें (जैसे `ollama pull llama3.2`) और प्रदाता के रूप में **Ollama** चुनें। अगर यह डिफ़ॉल्ट पते पर नहीं चलता, तो **प्राथमिकताएँ** → **AI** में **सर्वर URL** बदलें (डिफ़ॉल्ट `http://localhost:11434`)।

:::note
हर प्रदाता अपने API के उपयोग के लिए शुल्क लेता है, जिसके लिए Audiotext ज़िम्मेदार नहीं है। API कुंजियाँ आपके सिस्टम के क्रेडेंशियल स्टोर में रखी जाती हैं। [फ़ाइलें और डेटा](/hi/reference/files-and-data/) देखें।
:::
